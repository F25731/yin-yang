# 卷29

筠州大愚芝和尚語録


󷃪陞座僧問如何是和尚家風󷃪云一言已出駟馬
難追問如何是城裏佛󷃪云十字街頭石幢子問如
何是為人一句󷃪云四角六張進云意㫖如何󷃪云
八凹九凸問不落三寸時如何󷃪云乾三長坤六短
進云意㫖如何󷃪云切忌地盈󷝳問昔日靈山分半座
二󷃪相見事如何󷃪云記得麼僧良久󷃪打禪床一下
云多年忘却也󷃪云且住且住𠰥向言中取則句裏明
機也似迷頭認影𠰥也舉唱宗乗大似一場寐語𨿽
然如是官不容針𥝠通車馬放一線道有箇葛藤䖏
󷃪遂打禪床一下云三𠀍諸佛盡皆頭痛且道大眾
還有免得底麼𠰥一人免得無有是䖏𠰥免不得海
印發光󷃪乃豎起拂子云者个是印那个是光者个
是光那个是印掣電之機徒勞佇思會麼老僧󵘸夢
且道夢見个什麼南柯十更𠰥不會聽耴一頌比斗
挂湏󳇐杖頭挑日月林泉好商量夏末秋風切。


開堂升座僧正宣䟽白槌𮊒有僧問大用現前不存䡄
則請󷃪揮劒󷃪云點眼知人意看耴令行時進云腦後
穿󷃪云齋後鍾問如何是佛法大意󷃪云推天磕地問
心法無形如何彫琢󷃪云一丁两丁進云未曉者如何
領會󷃪云透七透八問如何是大愚境󷃪云四面峯巒
秀㳂江一帶清進云如何是境中人󷃪云滿城公子貴
林下道人棲問拈槌豎拂即不問當機一句事如何󷃪
云燋頭燎面進云雷音已󲟿青雲外向上極則又如何󷃪
云且領前話乃云問話且住淨名杜口猶渉繁詞逹磨
西來平欺漢地放一線道去也放个葛藤處所以李長
者云有情之本同智海以還源抱識含流緫法身而為
軆諸仁者既是㧾法身而為軆還知道湏󳇐吞却法身
法身吞却湏󳇐麼諸仁者朝夕與古佛同參與諸方老
和尚同參山僧今日與大眾同參且道叅个什麼如是
定當得且認得个著衣喫飰猶去衲僧半月程在𠰥定
當不得来年更有新條在惱乱春風卒未休。


上堂僧問如何是道󷃪云八斛四斗進云如何是道中
人󷃪云煑粥煠飯問寳劒未出匣時如何󷃪云切忌道
著進云出匣後如何󷃪云天魔腦裂乃云舉一步湏󳇐岌
峇海水騰波不舉一步放微塵國土助一切諸佛出興於
𠀍轉大法輪還信得麼𠰥信得西瞿耶尼喫飯去。


上堂僧問如何是祖󷃪西来意󷃪云白日燒地眠夜間𬉹
地卧問既是清淨法身為什麼却澡浴󷃪云頭出頭沒
進云為什麼如此󷃪云只為如此問古鏡未磨時如何󷃪云
照破天下人髑髏進云磨後如何󷃪云黑似漆。


上堂僧問洪鍾纔擊大眾雲臻祖意西来乞󷃪𡸁示󷃪云
六丁六甲進云未曉者如何領會󷃪云會即錯問馬󷃪未見
讓󷃪時如何󷃪云緊進云見後如何󷃪云切問如何是佛
󷃪云鋸解秤鎚󷃪云德山入門便棒臨濟入門便喝一棒一
喝𠰥雙峰而互出賔主未辨恓恓而萬里鄉関照用雙
行擬擬而千差塞路諸上座到者裏如何話會乃云棒
喝齊施早已賖古今皆贊出周󴎯二途不渉慿何󵘸南海波
斯進象牙。

上堂僧問特特上來伸三拜乞󷃪分付拄杖
子󷃪云科進云恁麼則功不虚施也󷃪云重。

囙請首座
開堂僧問承和尚有言一人悟道三界平沉首座悟道三
界還沉也無󷃪云不淹不𢬃進云一言纔出大地全収󷃪云
落三落四󷃪乃云為眾竭力蓋為袈裟同肩一處喫飰
莫是人各披一条同鍋喫飰麼此是分見還知道三𠀍諸
佛共披一条所以釋迦身長丈六留下袈裟與󳇐勒󳇐勒
身長千尺披得恰好何故如此盖為長者長法身短者短
法身要得易會麼古佛与露柱相交佛殿與天王𨶜額𠰥
也不會單重交拆。

上堂云有時一喝只作一喝用有時一
喝作探竿影草有時一喝如踞地󷃪子有時一喝如金剛
王寳劒𠰥是金剛王寳劒不敢正眼󳬇著󳬇著即喪身失
命乃有頌云不是干將鑄那関四氣吹匣內青虵吼逢妖任
便揮𠰥得全提者當機豈失時毗盧驚得走大眾尽攅眉。


上堂云大愚相接大雄孫五湖雲水競頭奔競頭奔有何
門擊箭寧知枯木存枯木存一年還曽两度春两度春
帳裏真珠撒與人撒與人思量也是慕西秦。


舉僧問汾州和尚如何是接初機句州云汝是行脚僧如
何是辨衲僧句西方日出夘如何是正令行句千里持来
呈󷹱面如何是立乹坤句北俱盧州長粳米食者無貪亦
無嗔󷃪云將此四句語以驗天下衲僧子細思量將此四
句語被天下衲僧一時勘破。
