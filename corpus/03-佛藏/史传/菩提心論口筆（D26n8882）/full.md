# 菩提心論口筆

菩提心論口筆



第三言三摩地者真言行人如是觀已云何
能證無上菩提。



。



當知法尒應住普賢大
菩提心。



。



一切
眾生本有󷨊埵為貪瞋癡煩𢚰之所󶧠故。




。



諸佛大悲以
善巧智。



。



󵘸此
甚深秘密瑜伽。



。



令修行者於內
心中觀日月輪。



。



由作此觀照見
本心湛然清淨猶如滿月光遍虚空無所分
別。



。



亦名無覺了亦名淨法界亦名實相般𠰥
波羅密海。



。



能含種種無量𭹀寳三摩地
猶如滿月󷶫白分明。



。



何者為
一切有情悉𭇥普賢之心。



。



我見自心形如月輪何故以月輪為
喻為滿月圓明體則與菩提心相類。



。



凡月輪有一十六分喻瑜伽中金
󵥳󷶁󵘁至金󵥳举有十六大菩󷨊者。



。



於三十七尊中五方佛位各表一智
也。



。



東方
阿閦佛由成大圓鏡智亦名金󵥳智也南方
寳生佛由成平等性智亦名灌頂智也西方
阿𢏏陀佛由成妙觀察智亦名蓮華智亦名
轉法輪智也北方不空成就佛由成成所作
智亦名羯磨智也中方毘盧󴎯那佛由成法
界智為本。



。



已上四佛智出生四波羅密菩󷨊焉
四菩󷨊即金寳法業也三世一切諸聖賢生
成養育之母。



。



於是󴖄
成法界體性中流出四佛也。



。



四方如來各攝四
菩󷨊東方阿閦佛攝四菩󷨊金󵥳󷨊󵘁金剛
王金剛愛金剛善哉為四菩󷨊也南方寳生
佛攝四菩󷨊金󵥳寳金󷶨光金󷶨幢金󷶨笑
為四菩󷨊也西方阿𢏏𨹔佛攝四菩󷨊金剛
法金剛利金剛因金剛語為四菩󷨊也北方
不空成就佛攝四菩󷨊金󵥳業金󵥳護金剛
牙金󵥳拳為四菩󷨊也四方佛各四菩󷨊為
十六大菩󷨊也於三十七尊中除五佛四波
羅密及後四攝八供養但取十六大菩󷨊為
四方佛所攝也。



。



又摩訶般𠰥經中內空至無
性自性空亦有十六義。



。



一切有
情於心質中有一分淨性眾行皆備其體𭫸
㣲妙皎然明白。



。



乃至
輪廽六趣亦不變易如月十六分之一。



。



凡月其一分明相𠰥當合
宿之際但為日光奪其明性所以不現。



。



後起月初日日漸加至十五日
圓滿無礙。



。



所以觀行者初以阿字發起
本心之中分明只漸令㓗白分明證無生智。




。



夫阿字者一切諸法
本不生義。



。



即讃阿字是菩
提心義頌曰。



。





八𰱒白蓮一肘間炳現阿字素光色


禪智俱入金剛󶧠召入如來寂靜智





。



扶會阿
字者揩寔决定觀之當𮗚圓明淨識。



。



𠰥𦆵見者則名見真勝義諦𠰥常見者
則入菩󷨊初地𠰥轉漸增長則廓周法界量
等虚空卷󷨴自在當具一切智。



。



凡修習瑜伽觀行人當須具修三
密行證悟五相成身義也所言三密者一身
密者如結契󴖄召請聖眾是也二語密者如
密誦真言令文句了了分明無謬悮也三意
密者如住瑜伽相應白淨月圓滿觀菩提心
也。



。



次明五相成身者
一是通逹心二是菩提心三是金󷶨心四是
金󵥳身五是證無上菩提獲金剛堅固身也
然此五相具備方成本尊身也其圓明則普
賢身也亦是普賢心也與十方諸佛同之亦
乃三世修行證有前後及逹悟已無去來今。




。



凡人
心如合蓮華佛心如滿月此觀𠰥成十方國
土𠰥淨若穢六道含識三乗行位及三世國
土成壞眾生業󶐉別菩󷨊囙地行相三世諸
佛悉於中現證本尊身滿足普賢一切行願。




。



故大毘盧舎那經云如是真實心
故佛所󶧺󵘸。



。




問前言二乗之人有法執故不得成佛今復
令修菩提心三摩地者云何󶐉別󷨽二乗之
人有法執故久久證理沉空滯寂限以刧數
然發大心又乗散善門中經無數刧是故足
可猒離不可依止。



。



今真言行人既破人法上執𨿽
能正見真實之智或為無始間隔未能證於
如來一切智智故欲求妙道修持次第從凢
入佛位者。



。



即此三
摩地者能逹諸佛自性悟諸佛法身證法界
體性智成大毘盧󴎯那佛自性身受用身變
化身等流身。



。



為行人未證故理冝修之。



。




故大毘盧󴎯那經云悉地從心生如金剛頂
瑜伽經󵘸一切義成就菩󷨊初㘴金剛座取
證無上道遂蒙諸佛授此心地然能證果。




。



凡今之人𠰥
心决定如教修行不起干座三摩地現前應
於是成就本尊之身。



。



故大毘盧󴎯那經供養次
第法云𠰥無勢力廣增益住法但觀菩提心
佛󵘸此中具万行滿足淨白純淨法也。



。



此菩提
心能包藏一切諸佛㓛德法故𠰥修證出現
則為一切導師。



。



𠰥歸本則是密嚴國土不
起干座能成一切佛事。



。



讃菩
提心曰𠰥人求佛慧通逹菩提心父母所生
身速證大覺位。



。




金剛頂瑜伽中發阿耨多羅三藐三菩提心論也。




。
