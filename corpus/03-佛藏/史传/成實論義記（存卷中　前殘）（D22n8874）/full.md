# 成實論義記（存卷中　前殘）

。



他人󷜎可󵘸…
人我󷜎可󵘸。



。



󷜎應如是分別水等。



。




意品。



。



色入相品。



。



眼入滅色相…
是𩂜應當知。



。



󷞝相品。



。




香品。



。




汝言反覆有過。



。



識論中立无數品。




。



心意識體一而名異。



。




若法能緣是名為心。



。



荅曰受想󵓕皆心別名知道品。



。




汝以若名字破心𰚆我󷜎以名字破心。



。



无相應品。



。



見是見等者。



。



汝言煩惱染
心故相應无有此理。



。



若心本性汙貪恚何為。



。



汝言心垢故眾生垢。



。




汙相續故說名染心。



。



多心品。



。



法相在心力能了知不以住
故。



。



想陰品。



。



身假法
相故名為想。



。



又以想三種差別身緣。



。



問曰身假法焉想是事不然者。



。



荅曰此實是兼以想名說者。



。



一過去。



。




問曰相義云何。



。



荅曰緣即是相者。



。




受論中受相品。



。



若增身心是名為樂者。



。




故知樂受󷜎无。



。




荅世俗名相故有樂。



。



若實无樂何得
說三。



。



荅曰若實有樂受應說其相。



。




行苦行。



。




辨三受品。



。



問曰若以觸󵓕因故有三受者一切
心行皆名為受。



。



故知緣及諸相但能生苦
者。



。



問曰無漏諸受󷜎是苦也。




。



云何別有諸
心󵓕法。



。



荅曰即是一受緣中行異故有差別。




。



諸心󵓕法至此󵓕如
先說。



。



是一切法在身中時。



。



又多以心䏻起煩惱。



。




何故宣說樂中貪使。



。



荅曰苦受不應貪。



。



癡一切𩂜使。



。




問曰但扵苦樂中生癡。



。



荅曰此経自說者。



。




扵餘事不知者。



。




是故此經原如是說。



。



若非不苦不樂受无明不
使者。



。




󷨽曰是人扵不苦不樂受中生三種心。



。



人若未通達苦集󵓕。



。



現在世受不約自知。



。



荅曰此経意說人受是故无過。



。




以意䏻緣故󷜎无各。



。



世󷡿󷜎有因中說果故。




。



又是人先受樂受
然後身相。



。



問曰為以受者
故名受可受故名受。



。



以覺緣故名為受樂。



。




人眾生受此故名可受為受。



。



問曰眾生不名為受。



。



荅曰名義如
是者。



。



五受相品。



。



行陰中思品。



。



如說㑅起皆依扵受。



。



又経中說我即是動𩂜。



。



問曰汝謂求是思者此是受相非是思也。



。



又汝謂願是是思者是󷜎不然。



。



󷨽願名習。



。



問曰若欲分願名思者則无无漏思。



。




又思為愛因。



。



又汝言思是愛因是󷜎不然。




。



行󵓕因緣皆以是󷨽。



。



是故貪為思因。



。



後業迴向。



。




觸品。



。




觸因緣受。



。



󵘸
六觸眾。



。



又経中󵘸應觀无明法觸。



。



識生然後受想諸法
生。



。



念品。



。




喜品。



。



信品。



。



懃品。



。




憶品。



。




念識󵓕諸法皆應名憶。



。




󷨽曰今識󵓕法󷜎󵘸是憶。



。




覺觀品。



。




成實論義記卷中　比丘其甲
