# 卷2

特賜興禪大燈國師參詳語要二




雪竇語錄中事



一日云此大講堂洞開。



。



東方日輪昇天則
有明曜。



。



中夜黑月雲霧晦暝則復昏暗。



。




戶牖之隙則復見通。



。



墻宇之間則復觀壅。



。



分別之處則復見緣。



。



頑虚之中遍
是空性。



。



鬱㶿之象則紆昏塵。



。



澄霽
斂氛又觀清淨。



。



慚愧釋迦老子。



。



󵘸甚還
與不還。



。



文殊堂裏万菩薩到處覔
不得。



。



元來揔在者裏。



。



刢利漢一
見便請拗折拄杖。



。



上堂㪯鏡清問僧近離
甚處。



。



云石橋。



。



清云本分事作麼生。




。



云某甲近離石橋。



。



清
云我不管尒石橋本分事作麼生。



。



何云
和尚何不領話。



。



清便打。



。



僧云某甲話在。



。



清云尒但喫棒我
要話行。



。



竇云然則𠋣勢欺人柰緣事不孤
起。



。



者僧若能慎初護末棒則須是鏡清自
喫。



。



㪯雲門大師示眾云尒若不相
當。



。



且覔个入頭處。



。



微塵
諸佛在尒舌頭上三蔵聖教在尒脚跟底。



。



不如悟
去好。



。



還有人悟得麼出來對眾道看。



。



竇拈云然則養子之緣。



。



麼爭柰壓
良為賤快慶平生其間忽有不甘底出掀倒繩床豈
不是大丈夫漢。



。



然雖如此且問據个甚麼。




。



竇驀拈起拄杖。



。




云洎合停囚長智。



。



擊繩床一下便下座。




。



上堂云窮諸玄辨若一毫致於太虚。



。



竭𠀍樞機似一滴投於巨壑。



。



不
如歇去好。



。



還會麼。



。



客
亭不遠。



。



上堂云青蘿夤緣直上寒松之
頂。



。



白雲淡泞出沒太虚之中。



。



竇拈起拄杖。



。



云
國師眼睛在者裏。



。



瞌睡漢七穿八󲈺甚
處得來。



。



一日㪯乾峯示眾云舉一
不得舉二。



。



放過一著落在第二。




。



雲門大師出眾云昨日有人從天台來
却往南岳去。



。



峯云來日不要普請。



。



竇云諸禪德雲門老漢只解一手擡不
能一手搦。



。



還有共相著力底麼試露爪牙看。




。



上堂云不得春
風花不開花開又被風吹落。



。



尒若明得褒
貶句。



。



未必善因而招𢙣果皈
堂。



。



一日云古人道其為也形。



。



其寂
也󳸓。



。



轉變天地自在縱橫。



。




河沙而用混沌而榮。



。



誰聞不喜誰聞
不驚。



。



如何以無價之寳隱在隂入之坑。



。



竇以拄杖擊一下。



。



云打破
了也。



。



寳在甚處。



。



有時
云不󱳔之令大眾必合依行。



。



上堂
云万法本閑。



。



而人自閙。



。



國
師走入露柱裏去也。



。



見麼見麼。



。



良
久。



。



云出頭便死皈堂。



。



示眾云廻而更相涉。



。



拈起拄杖。



。



云頭上是天脚下是地。



。



眼前綠水
背靠青山。



。



衲僧道我會也忽若
騎驢入尒鼻孔裏。



。



牽牛入尒眼睛中。




。



又作麼生商量。



。




上堂云欲得現前莫存順逆。



。



者裏參見祖
師了。



。



更買草鞋行脚。



。



三千里
外也被雪竇穿却鼻孔。



。




一日㪯馬祖上堂眾方集。



。



百丈出
捲席。



。



祖便下座。



。



諸
方皆謂奇特漝麼舉還當麼。



。



若當譬若
水母以蝦為目。



。



若不當又空讚歎󱺤个
作麼。



。



眾中一般漢乱踏向前問古人意旨
如何。



。



更有老底不識好𢙣對云將謂仙陀
客。



。



又云來日更到座前。



。



苦哉苦哉如此自稱宗匠欲開人天眼目驢𥝝去。




。



諸上座雪竇當時若見伊出來捲席劈胷
與一踏。



。



令坐者倒者俱起不得。



。




且要後人別有生涯去免見互相鈍置豈不个个英
靈底漢。



。



還會也無皈堂。



。



上堂云
虚空為皷。



。



湏󳇐為槌。



。



打者甚
多。



。



聽者極少。



。



且問誰是解
打者莫謗𥂁官好。



。



只如南泉道王老師不
打者破皷咦法眼云王老師不打過兩个既不柰何
一个更是懡㦬。



。



上堂云還有閙
市裏出頭底麼。



。



良久。



。



云
不如䇿杖皈山去長嘯一聲烟霧𭰹便下座。



。



㪯僧問趙州學人乍入叢林乞師指示。



。



州云喫粥了也未。



。



云喫粥了也。



。



州云洗鉢盂去。



。



雲門大師云且
道有指示無指示。



。



若云有
向佗道什麼。



。



若道無何得悟去。



。



竇拈云我不似雲門為蛇𦘕足。



。



直言向尒道。



。



問者如蟲蝕木。



。



答者
偶尒成文。



。



然雖恁麼瞎却衲僧眼。



。




作麼生免得此過。



。



諸仁者要會麼。



。



還尒
趙州喫粥未拈却。



。



者僧喫粥了。



。



雪
竇与尒拄杖了皈堂。



。



㪯雲門大師云盡十
方𠀍界乹坤大地天下老和尚。



。



以拄杖一劃。



。



云百雜碎。



。



竇云者老漢是即是。



。



要且未有出身之路。



。



如今拄杖在雪
竇手裏。



。



復橫按。



。



云東西南北甚󵕯得來。



。



㪯僧問投子如何是十身調御。



。



投子下繩床立。



。



又問凢聖相去多少。



。



投子下繩床立。



。



竇云此公案諸人無不委
知。



。



若漝麼㪯天下衲僧盡為念話杜
家。



。



雪竇莫有長󵕯也無。



。



試為大
眾㪯看。



。



凢聖相去多少投子下繩床立。



。



如何是十身調御投子下繩床立。



。



且道与前來㪯底同別。



。



若道一
般許上座具一隻眼。



。



若云別有竒特也許上座
具一隻眼。



。



復更開一線道。



。



凢
聖相去多少請上座下一轉語。



。



如何是十身
調御答一轉話。



。



非但參見投子亦乃知雪竇
長󵕯。



。



或若揔道下繩床立。



。



惜耴
眉毛。



。



便下座。



。



㪯洞山聦和尚每見新
到便問溈山水牯牛上座作麼生會。



。



前後皆不相契。



。



竇到亦乃垂問。



。



竇云後人標牓。



。



洞山擬道。



。



竇以坐具拂一下便行。



。



洞山云且來上座。



。



竇云未參堂。



。



㪯雲門大
師云三乗十二分教。



。



逹磨西來。



。



放過即不可。



。



若不放過不消一喝。



。



竇随㪯了便喝。



。



復云大眾好喝落在甚
處。



。



若要鼻孔遼天。



。



辨取者一喝。




。



便下座。



。



竇因事示眾云杜耳目於
胎殻。



。



掩玄象於霄外。



。



而責宮商
之異。



。



辨玄素之殊底是甚麼人。



。



還知落處麼。



。



那一个者一个。



。




兼本三人。



。



放過一著。



。



便下座。



。



上堂
云三十𥝝來尋劒客。



。



有麼有麼。



。




幾囬葉落又抽枝。



。



衲僧眼光失却了也。




。



自從一見桃花後。



。



填溝塞壑。



。



直至如今更不疑。



。



敗軍
之將。



。



以拄杖卓地一下。



。



云
看。



。



便下座。



。



㪯皈宗問
僧甚處去。



。



云諸方學五味禪去。



。




宗云我者裏有一味禪為甚不學。



。



僧
云如何是一味禪。



。



宗便打。



。



僧云莫打某甲會也。



。



宗云尒作
麼生會。



。



僧擬開口。



。



宗又打。



。



黃檗聞㪯云馬大師出八十四貟
善知識。



。



問著个个屙轆轆地。



。



只有皈宗老較些子。



。



竇云以彊欺弱
有甚麼難。



。



我者裏有一味禪為甚麼不學
但向道収。



。



待伊拈起。



。



有般無眼漢
只管喫。



。



吽吽。



。



雪竇門下誰
敢。



。



便下座。



。



上堂云胡蜂不戀舊時窠。



。



猛將不在家中死。



。



若是个漢聊聞㪯
著剔起眉毛便行。



。



一日六人
新到竇問云還有作家禪客麼。



。



參頭云
和尚道什麼。



。



竇云點即不到。



。



僧
擬議。



。



竇便喝。



。



僧無語
竇云龍頭蛇尾。



。



復問第二个僧指參頭
云和尚問何不祗對。



。



竇與一掌僧無
語。



。



竇復指云第三其僧茫然竇
云一狀領過。



。



上堂僧問如何是時節因緣竇云
瞌睡漢。



。



僧便喝。



。



竇云詐惺
惺。



。



復云譬若世界壞時。



。



大水競作。




。



其間無量眾生或沒或未沒。



。



互相悲號仰󷧨蒼蒼皆云相救。



。



當尒之
時四禪天人一見高聲便喝。



。



咄哉眾生我
預曾報你。



。



令頻頻上來。



。



你都不聽。



。



如今有甚救󵕯。



。



乃拍手
一下。



。



云皈堂。



。



上堂云乹坤之
內宇宙之間。



。



中有一寳。



。



挂在壁上。



。



入。




。



逹磨九𥝝不敢正眼覷著。



。



如今
衲僧要見劈脊打。



。



上堂僧問如何是佛竇
云頭髼鬆耳卓朔。



。



僧云不會。



。



竇云
堪笑堪悲。



。



復云不著便也不柰何。



。



尒從江南江北󷛼笠子下為什麼拶破洛浦遍參
底。



。



上堂云乹坤把定即不無尒作麼生是
手擎日月底句。



。



又云周遊四天下道
我知有須󳇐頂上著得幾人。



。



復云㪯
步已經諸佛剎是尒草鞋󳑚破多少。



。



上堂云長觜鳥芳樹不棲喃喃獨語。



。



摩斯吒滄溟不入戰戰却廻。



。



三
十秊後悟去。



。



提起手云吽吽。



。



便下座。



。



上堂㪯在眾日僧問如何是佛
竇云四眾圍遶。



。



如何是湼槃竇云雙林樹
下。



。



復云便是釘觜銕舌漢也卒話會不及
皈堂。



。



有時竪起拄杖。



。



云
洪機在掌排巨靈擘太華之峰。



。



復橫
案云明鏡當臺絕演若逐東西之逕。



。




又以拄杖一劃。



。



云比擬張麟兔亦不遇
便下座。



。



上堂云不與一法
作對便是無諍三昧。



。



或是个漢聞
我㪯著悉能坐断有甚麼近處。



。



雖
然如此向後莫辜負人好便下座。



。



上堂㪯古人
道明眼漢沒窠臼。



。



我且問尒各從德山
林際下來。



。



棒喝向尒不能󲣿。



。



語
言向尒使不著。



。



我既如此。



。



汝合必然。




。



又作麼生露得个消息。



。



令
雪竇知尒是个風不入底漢去便下座。



。




一日三僧辤竇把住云天無門地無戶乱走衲僧擬
往何處。



。



僧皆無對。



。



竇
劈靣唾云枉喫我多少粥飯。



。



便推出。



。



示眾云摩竭正令譬若披沙揀金。



。



毗耶杜辤頗類守株待兔。



。




設使頓開千眼。



。



未辨機関。



。



點著不
來。



。



白雲万里。



。



㪯永嘉云六般
神用空不空。



。



一顆圎光色非色。



。



雲門大師拈起拄杖。



。



云是色非
色。



。



竇云雪竇即不然。



。



圎光一顆
儱侗真如。



。



神用六般和泥合水。



。



塻窑人設齋且致水中拈月致將一問來。



。



有時云袖頭打領腋下剜襟。



。



諸方一任翦裁。



。



南山起雲北山下雨衲
子作麼生話會。



。



一日上堂大眾纔集。




。



竇云一任諸方貶剝。



。



便下座。



。



㪯僧問乾峰十方薄伽梵一路湼槃門路頭
在什麼處峰云在者裏。



。



竇代僧便喝。



。



復有僧問長慶慶云問取堂中第二
座。



。



竇代僧云錯。



。



復有僧問
雪竇竇云堕坑落壍。



。



自代云作賊人心虚。




。



上堂云糞掃堆上現丈六金身遇賤則貴。



。




赤肉團上壁立千仞遇明則暗。



。



鼻孔遼天底衲
僧試辨雪竇為人眼也。



。



示眾云一法不通万
緣方透。



。



會與不會成群作隊。



。



築著磕著一時拈却。



。



管取乾坤
獨露。



。



便下座。



。



上堂云禪河随浪靜。




。



定水逐波清。



。



若拄杖子是浪衲僧
便七縦八橫。



。



忽乾坤大地是浪便見
扶籬摸壁。



。



且道放行好把定好。




。



一日云春雷已發陽鳥未啼俱迷身
句即不問尒透出一字作麼生道。



。



上堂云巢知風󲈺知雨刢利衲僧未可相
許。



。



若問如何苦哉佛陀參。



。



㪯馬大師云一切
語言是提婆宗以者个為主。



。



雲門大師
云好語只是無人問我。



。



僧便問如何是提
婆宗門云西天九十六種尒是㝡下種。



。




竇云赤幡被者僧奪了也便下座。



。



一日云
山河無隔礙光明處處透。



。



傅大士
騎驢入尒鼻孔裏。



。



見尒諸人不惺惺却
皈雙林寺去也便下座。



。



㪯僧問翠微
自到和尚法席每沐上堂不蒙一法示誨意在於何。




。



微云嫌个什麼。



。



僧復問洞山山云
爭恠得老僧。



。



後有僧問法眼眼云祖師來
也。



。



竇云兩个老漢被者僧穿却。



。



唯有法眼與他同參。



。



若是雪竇門下喫棒了
趕出。



。



上堂云種種幻化皆生如來圎覺。



。



竇云住住三世諸佛是幻六代祖
師是幻天下老和尚是幻。



。



復拈起拄杖。



。



云拄杖子是幻那个是圎覺。



。



良久
以拄杖擊繩床一下。



。



云幻出。



。



大眾擬議。




。



竇云者一隊漆桶揔無孔竅以拄杖一時趂
下。



。



㪯夾山問僧甚處來。



。



云湖
南來。



。



山云曾到石霜麼。



。



云要路
經過爭得不到。



。



山云羕聞石霜有毬子
話是否。



。



云和尚也須急著眼。



。




山云作麼生是毬子。



。



云趒不出。



。



云作麼生是毬杖也。



。

特賜興禪大燈國師參詳語要二





大燈国師行狀


大應国師唱臨済宗旨扵橫嶽万壽建長也󷧣乎四
十年矣其間摳衣者不知󷧣何師其一也師諱妙超
宗峰其號也生扵󵘯州揖西縣紀氏子父母禱扵本
州書冩山如意輪觀音母夢一僧手󵈢白花開扵五
葉而与之有妊󷓗而後如寐而不寤至其誕之時熟
睡而不知也保母俄聞呱地一聲徃而見之未澡浴
而肌體瑩㓗克𭭛克嶷頂骨聳立伏犀插額目光射
人随面前人能轉顏目五嵗時見人發刀扵硎云何
為而作也云貴圖快利云不快利󷄄有快利你還知
麼其人罔測師呵󷓗大笑触事以言所挫人若比親
󷓺有諫而欲使住之者拈棒便打鄉黨稱為神童矣
十有一嵗而師事扵書冩山戒信律師每屏坐靜処
志厭俗塵經書過目成誦一日慨然云假使究九流
三蔵百家異道書爭若入不立文字直指單傳宗未
剃染而發足至京城并相州參問諸尊宿〃〃雖氣
吞佛祖底不敢嬰其鋒謁建長〃老問曰路逢死蛇
莫打殺無底籃子盛将皈意旨如何老曰放下着者
般底直下便看耴師云只如道直下便看耴如何老
擬議師乃喝造万壽問佛國禪師曰佛法無多子著
衣喫飯処即是纔作恁麼理會早是不是了也国云
未知恁麼㕝以前与而今如何區別師云區則區別
則不別国云試區別看師指露柱云喚者亇作露柱
則与背時逈區不喚者亇作露柱則而今已別国云
豈是佛法師云和尚好亇時莭國云只与麼受用与
老僧別師云若見有和尚某甲佗日悔去国云平生
日用処直下道來看師云步󷓗踏着毘盧頂言󷓗勘
破維摩詰次日又來問云昨日与今日請師辨別国
云說什麼昨日直道今日事師云雲従龍風従虎国
云雲未起風未來時如何師云天上天下唯我独尊
国云雲門云我當時若見一棒打殺与狗子喫貴圖
天下太平如何師曰一口吞𨚫了也國橫点頭曰此
語不敢肯師乃喝国亦喝師又喝而出去国送出門
曰我見多少学者未嘗逢如公俊底冝祝髮披衣棟
梁吾道師翌日重參佛国〃見來曰古人云大用現
前不存䡄則時如何師曰和尚未問以前已現前久
矣国云在甚麼処師曰夜來狂風吹折門前一枝松
國云如何是狂風師搖手中扇子国休去師云狂風
豈不是扇子国大笑云綐見相似𨚫也蹉了師扵此
服膺矣自歎曰人身難得佛法難遇󷓗賤則貴豈丈
夫志遂落髮受具旦夕留心扵此㕝一夕坐僧堂聞
僧隔壁誦百丈語云靈光独耀逈絕根塵躰露真常
不拘文字驀然有省夜半扣門呈其見解国云既是
真正見解也冝建法幢立宗旨厥後大應国師應
󳓇自橫岳來亰師舘于韜光庵師在相冽聞其手叚
辛辣趨于亰徑詣其室問云学人遠󷓗來化下請師
一接師云老來無力且坐喫茶師云恁麼用去只恐
不肯国師云你是新到爭知這裏㕝師云千里同風
豈不是君子国師云室中物色你試指出看師云七
九六十三国師云無慚愧漢來処也不知師云謹謝
老師以学人托上梵天国師云今日自領出去明日
事你作麼生師云天際日上月下檻前山𭰹水寒国
師云一死不𭁡活師便休国師便問五祖演示佛眼
云牛過窓櫺頭角四蹄全出尾巴因甚出不得你試
下一轉語看師云曲心已露国師云如何是曲心師
云拄天拄地国師大笑云与麼空至他日有悔三日
後師下語曰𣏐卜𦗟虚声国師云方得相似自尓晝
参暮請不敢退轉国師時臥󳱈經旬閉方丈戶止学
者㕘問唯師見許參請国師云你是天然衲子也不
是一兩生參学士国師羕　詔住京城萬壽師従之
侍巾瓶国師示以翆岩眉毛在麼雲門云関之語也
師下語云將錯就錯国師曰是則是你能扵関字着
精彩他時別湏有生涯德治丁未国師赴于相州住
建長師乃參随至彼未經十日因案上放在鎖子忽
然打透関字到了圎融無際真實諦當大法現前処
汗流浹背急趨方丈下語曰󷧣乎同路国師大愕云
夜來夢見雲門入吾室你今日透関字你是雲門𭁡
來也師掩耳而出翌日呈二偈云一囬透過雲関了
南北東西活路通夕處朝遊沒賔主󷗿頭󷗿底起清
風　透過雲関無旧路青天白日是家山機輪通変
難人到金色頭陁拱手還　妙超胸懷如是若不孤
負師意伏望賜一言近擬󷧡故都莫惜尊意以為大
幸耳　国師掇茟自書其後云你既明投暗合吾不
如你吾宗到你大立去只是二十年長養使人知此
證明矣為妙超禪人書巨福山南浦紹明延慶戊申
臘月国師示滅心䘮既畢󷧡亰而卜居扵洛水東衲
子纔六七輩刻苦自厲至忘寒飢一夕夢有六人僧
狀若羅漢居第一位僧云出𠀍時至何不出也師云
仁義盡従貪𩂜断僧即頷而以竹針挑破𦛁後云為
你抉出貧肉覚後頭𦛁尚痛焉不󷧣而去雲居徙居
城北紫野不立佛殿唯𣗳法坣洗心子玄恵法師偕
儒者九人奏扵朝欲破禪宗禪宗若有奇特㕝吾俯
豈敢諸儒徵詰諸方禪將無有當意者諸儒聞師名
而特來問云禪宗手叚如何師云以󷝳偽示真實儒
云聖人有󷝳言否師云有云既是聖人有甚虚言師
云不見孟子有之象謂已殺舜了而入宮見舜在床
琴舜見象來而喜豈不是󷝳偽其間激揚鏗鏘問荅
罷儒却問師云畢竟如何决断北義去也師云舜却
殺象了也諸儒皆稽䫙而執弟子礼就中洗心子入
室參禪造詣不淺不勝崇信之至󲣿第宅而作大德
方丈今雲門庵是也師氣宇如王人少近傍数年罕
有為檀越外護者一旦　萩原法皇聞其風而召入
內　上遣中使告師而𣣔披道服而除一重坐席談
話師𭁡三乞着袈裟而對坐一一許之　帝勑佛
法不思議与王法對坐師奏云王法不思議与佛法
對坐　上動龍顏一日　上勑問云不与万法為侶
者是什麼人師搖手中扇子云皇風永扇一日面有
勑云朕欲以大德寺為朝廷第一祈禱処去師受命
而云唯󷓗　後醍醐天皇即位如前所勑礼敬󳇐敦
寵㤙益渥　帝召弟子僧入內　帝問云不与万法
為侶者是什麼人僧起而鞠躬僧却奏云不与万法
為侶者什麼人　上以手中珪劃一劃云這亇聻師
上法語云億刧相離而不相離尽日相對而不相對
不審是什麼物請𦗟　綸言帝御茟書紙尾昨夜
三更露柱向和尚道了也　上書投機頌賜師云二
十年來辛苦人𨒦春不換旧風𤇆着衣喫飯恁麼去
大地那曾有一塵又書紙尾云弟子有亇悟処以何
驗朕師又書云老僧恁麼驗聻又　御茟書古人節
角誵訛則語問師〃謹書紙奏對不可勝計　勑洞
院都護請師入　禁掖就五莭　所俄設法座請師陞
座面前懸百丈禪師頂相　帝亦扵法座右側設御
榻側𦗟月𡖖雲客皆在扵左右前後拈香祝　聖
罷師下法座　帝亦下御榻師奏云臣僧適來許多
鄙俚言說㓛皈何処　帝指百丈真云百丈禪師為
證明師云此外更無有人作證明麼　帝便竪起拳
頭師云与麼則南山朝北闕夜〃見明星　帝瞬目
而󷑜揖師鞠躬而出去　皇情大恱次日賜兼金縑
帛󵓕兩朝特賜興禪大灯高照正灯国師号所賜庄
田濃州長森播州小宅三職方并浦上総州遠山方
御厨信州伴野紀州高家仍見下官府宣正中年
南禪虚席　詔下請師𭁡三竟不赴建武初下　綸
旨云大德禪寺冝處五山之一也師却而不受之又
下　詔云冝相並南禪淨𠛴　萩原法皇　後醍醐
天皇親　宸翰有一流相羕不許他門住涇渭殊流
貽言扵󳹯華　御製臨之刊之見懸扵󷘳額左右
萩原法皇自剪　御髮造小󷘳安扵其中被置在靈
光󷘳左邊盖為結与大燈當󷓗來𠀍香火緣也筑州
太宰府都督司馬少卿上帖扵師請住橫岳山崇福
禪寺詣闕而以此㕝奏　帝堅留之重敷奏以師翁
行道地　帝乃允之纔作百日主而告退还皈于大
德垂三轉語示衣云朝結眉夕交肩我何似　露柱
𥁞日徃來我囙甚不動　若透得亇兩轉語一生參
学㕝了畢建武丁丑冬一夕召首座德禪開山徹翁
和尚也曰我化緣已𥁞衣法并本寺末寺住持職㕝
悉付与你克令子孫接續使不断絕未󷧣得󳱈臘月
二十一日夜書亨首座相従久矣悟徹既人皆知之
語而授焉又示遺誡扵諸弟子云我行而後置骨扵
丈室莫別造󷘳其有以也夫汝󵓕冝委悉二十二日
午時欲端坐胡床示滅而久有足󳱈患不克結跏趺
坐首座出以比為憾語師自以兩手加左足扵右股
上左膝傷折血流霑衣至今血痕尚存焉乃書辝𠀍
偈云截断佛祖吹毛常磨機輪轉処虚空咬牙擲茟
而逝大鑑禪師時住南禪有人傳誦遺偈鑑聞而大
驚云不意日本有明眼宗師也平生欲會面而人皆
沮止之遺恨不少欲赴茶毗而緣有朝廷祈禱㕝不
能也且遣僧人伺茶毗時至馳皈告之乃率大眾出
山門頭諷經遣侍者二人贈瓣香瓣香至今為寺什物世壽五十六僧臈三十四
門人悉遵遺誡親羕印可嗣其法者妙心関山和尚
興德海岸池寺白翁野州了翁長福璧峰金󷦆日山
貞庵主可監寺和典座各拠一方接引学者師平居
与物為春無町畦也迄于夫陞堂而𬼌拂子開室而
握竹篦以機攻機如張良躡足而封韓信是賊知賊
若孫子减竈而敗龐㳙阿脩羅王托動三有大城金
翅鳥王擘破娑竭羅海談笑而起臨濟扵己仆叱咜
而破雲門之機関到于極処穿山透石壁鼻孔血淋
淋有語錄三帙一帙雪竇錄着語有自來矣按夫雲
門遺誡云吾滅後置吾扵方丈中上或賜󷘳額󷑜懸
扵方丈勿別營作又遺表云聯叨鳳詔累對龍庭継
奉頌宣重疊慶賜師示遺誡准雲門故㕝置骨扵方
丈󷘳賜靈光額󰮓兩朝寵光優渥嬰足󳱈患大應雲
門𭁡誕語𮈔髮不爽也大應滅後十有九白嘉曆元
年奉　詔開大德法堂一香供大應二十年長養記
莂若合符節入滅纔九十年矣夫何門󲊷冷落子孫
寢㣲所謂強弩之末勢不能穿魯縞者歟寔足歎息。
