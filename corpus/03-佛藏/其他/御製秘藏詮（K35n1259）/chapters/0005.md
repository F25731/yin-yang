# 卷5

御製秘藏詮卷第五　　　　　　　車





違道如山積




。




迷情去復來




。




貪財無布施




。




罪即犯靈
臺




。





順則菩提行




。




慈悲道眼開




。




眾生業力重





。




󰡷益
自心裁




。





知真不起妄




。




魔眾可哀哉




。




世界光
明裏




。




天花七寶臺




。





情悟脫迷津




。




祖宗何伴侶




。




真心妄不同




。




求百還千與





。





疑惑失真趣




。




分明聖慧開




。




一音從法界




。




龍
象影中來




。





興心詮像教




。




佛理卒難裁




。




萬卷真如
旨




。





󷦾然性相開




。





念徹無窮義




。




玄関秘不開




。




一真非鏁鑰




。




萬法眼前來




。





欲性本來差




。




冬寒如夏暑




。




迷途不
是緣




。




報應非言語




。





恒式持金偈




。




真風入座來




。




玄機娛自解




。




理性洞然開





。





習善保康哉




。




迷徒甚可哀




。




慈光燭法界




。




七寶湧樓
臺




。





除濁歸清世




。




業隨䧟刼摧




。




琉璃光瑩淨




。




勿染六塵
埃




。





求慧入幽微




。




疑緣多執處




。




慈悲四眾間




。




何用經營取




。





想絕是非跡




。




輪迴妙相開




。




眾生迷不
見




。




終
日路獃獃




。





俗態多昬翳




。




亦能障法身




。




光明照八極




。




物象盡成真





。





諦信成三寶




。




冝依作道隣




。




梵天興教
日




。




覺樹鎮長春




。





願為十方說




。




論千及萬與




。




日烏將月兔





。




照破無
眀處




。





語默皆為道




。




忘機絕妄塵




。




有無依妙理




。




誰作解空人




。





言妄迷情障




。




非空不是真




。




色心成相法





。




根種離埃塵




。





純熟如來智




。




多聞似不聞




。




無心即是道




。




象教紀經文




。





安置断非心




。




垢塵流土宇




。





但能日用真




。




不必更疑慮




。





和合歸真理




。




緣流性自純




。




菩提清淨境




。




經劫不生塵




。





迷背人難解




。




愛河彼岸津




。




未嘗興一念




。




色相擬
為隣




。





彼岸梁為搆




。




清波濁水津





。




非
心為筏喻




。




宿世有良因




。





樂道信非常




。




善心無猛虎




。




受持不
可思




。




枉用虛勞苦




。





曩刧何迷障




。




多成不解人




。




宗乘能了達





。




三界
好相親




。





垢膩昬諸意




。




如何見法身




。




為開方
便故




。




此理
卒難陳




。





抂用成顛倒




。




將心更問天




。




如來雖付囑





。




妙覺為誰傳




。





戒說是經文




。




十方逢信住




。




誦持有善緣





。




人好相
依附




。





來去何時了




。




菩提本不還




。




寧虧慈忍力




。




妙相得方
閑




。





人本有根性




。




真心即是緣




。




若明空實理





。




達
悟不遷延




。





種種関經教




。




真機四不遷




。




開通無阻滯




。




方見
法王㩲




。





定極無邊方




。




威光根信所




。




歸依大眾心




。




功德
恒沙土




。





東土方興教




。




如來一法傳




。




投林棲木
鶴




。




悟達理
無偏




。





西方極樂界




。




我佛智重宣




。




祖印相提挈




。




無心即受傳




。





賢聖本無障




。




真純達智
詮




。





求之則不現




。




虛己却安禪




。





釋法法皆真




。




恒沙非可𰚆




。




功成果自圓





。




梵說
鳴金鼓




。





愚騃眾生相




。




無能至道緣




。




如來本是實




。




却被妄情牽




。





舒展威儀德




。




天龍八部前




。




慈光
廻一照




。




苦趣息煩冤




。





卷則不盈手




。




行之極大千




。




塵勞當自
泯




。




聖法本如然




。





意解得無心




。




玄中不可𰚆




。




八萬四千門




。




誰
證斆䂓矩




。





疑了還無事




。




執之
情妄交




。




為緣成染污




。




迷夢不相拋




。





悟達曾無法




。




慈悲智轉高




。




等
閑空度日




。




勿染妄心勞




。





知足心常足




。




無情逐境勞




。




雖
居五濁內




。




色相意空高




。





經佛是因緣




。




真純人到處




。




若知大聖因




。




寂滅眾生苦




。





非為情牽迫




。




要知一字褒




。




不
能深論理




。




拂子用龜毛




。





取意非求願




。




能行性自高




。




用心無等
級




。




剗地妄煎熬




。





海聚百川水




。




奔騰勢自勞




。




因知
平等法




。




圓
滿智身高




。





論譯法王言




。




慈悲心救苦





。




文依理義玄




。




清淨善分付




。





降盡諸魔相




。




方知大
智高




。




性心無問處




。




自在不虛勞




。





伏妄虛空性




。




隨形影不
逃




。




因言無限意




。




百里望纖毫




。





御製秘藏詮卷第五



丁未歲高麗國大藏都監奉
