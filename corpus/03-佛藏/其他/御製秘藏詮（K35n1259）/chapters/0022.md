# 卷22

御製秘藏詮幽隱律詩卷第二十二　𦘺





我作一篇詩




。




人間天上
知




。




徒他皆解悟




。




細認理無私




。




邪妄終名利




。




顛狂勿信之




。




幽深豈易見





。




逢善即為
師




。





有年便僻靜




。




我意是人知




。




思
極通三界




。




含靈遶四維




。




從容
閑理道




。




動止
合規儀




。




但喜民安
樂




。




恒持萬載基




。





善人常快樂




。




清淨好歡娛




。




感激情分別




。




優
遊事且殊




。




炎蒸然燧火




。




世昧冷冰
壺




。




極意
誰消息




。




門
深且晏如




。





意思何興感




。




情來不暫休




。




安危陳計䇿




。




康濟入時流




。




細葉稀踈影




。




清風滿背秋




。




凄凉悲往事




。




白髮上人
頭




。





往事興人感




。




徘徊空寂
寥




。




湛然思古道




。




群品似相邀




。




春臺松栢靜





。




秋
風海岳搖




。




時遷何倐忽




。




落葉自零飄




。





坐謝幾光陰




。




周
才重古今




。




見機堪撫掌




。




取捨盡由心




。




緲邈情
何遠




。




清歡力不任




。




風前與月下





。




玄
妙海中深




。





何湏山下住




。




道性有閑位




。




園裏群飛鳥




。




花開向有香




。




幽深情自樂





。




老大減踈
狂




。




寂滅安居
靜




。





齊天地久長




。





老冝飡薄粥




。




省
睡一甌茶




。




風味全然減




。




花開任眾誇




。




慵來多冷澹




。




意
緒足交加




。




拄杖閑庭
立




。




怡情笑
月華




。





老漸惟慵墮




。




園林罷去遊




。




驕矜除
以定




。




常為世
情憂




。





隙地多荒草




。





祥煙落照樓




。




自娛
閑自樂




。




細水小波流




。





不言行教化




。




有位豈胡顏




。




雲靜眀開閉





。




人忙我自閑




。




畏繁
非市井




。





就靜覔深山




。




道士與和尚




。




杳𡨋天地間




。





三春無意賞




。




老大畏看花




。




雲
重思時雨




。




心憐落照霞





。




傷情
離別恨




。




壯志少年誇





。




短褐厚綿襖




。




神清澹薄茶




。





意遣隨冝樂




。




寂
然無是非




。




不欺終降福




。




大道隱玄機




。




廣施知達識




。




󱍮中有細󳏧




。





心生勿猶豫




。




善惡盡相依




。





少年多意氣




。




顏㒵比於花




。




老大將來至




。




容儀不用誇




。




黑髭隨日變




。




白髮笑天涯




。




賢者誰
高尚




。




昬衢業障遮




。





汝看浮生業




。





朝歡暮亦悲




。




笑迎先瞑目




。




惡至聚
愁眉




。




正直廻斜曲





。




冤逢不用推




。




小
人心似獸




。




君子定無
欺




。





大道常恭謹




。




眀
靈不降威




。




少言知有信




。




多事自招非




。




年壽看松栢




。




𭁺簪短布衣




。




我心忙也樂




。




清淨得同歸




。





夫生人怕死




。




螻
蟻命何輕




。




福業隨緣
寂




。





慈悲響善名




。




在
家行孝愛




。





食祿盡忠貞




。





天道不移改




。





佛心化有情




。





隔牖聞歌唱




。




爭如靜悄然





。




肆情饒過失




。




何似斆眀賢




。




樂善於身益




。




師資在眼前




。




若能依法則




。




謙謹更
周旋




。





遙觀七寶山




。




未到即無緣




。





菩薩因從地




。




金剛利福田




。





祛煩清世界




。




大化法人天




。




智
演窮難盡




。




閑心即是禪




。





苦學皆成癖




。




心灰似若愚




。




經書看不
倦




。




筆硯更相
於




。




室內明䆫
靜




。




磨
礱道不踈




。





翻成閑散誕




。




意外指迷途




。





向人言福善




。




福善自機關




。




喜怒大張口




。




愚癡似等閑




。




鑊湯知有罪




。




生死暫時
間




。




六賊常清淨




。




輪廻絕往還




。





寂靜人謌詠




。




愚情豈易知




。




但求心自樂




。




不怕面相欺




。




枉直回邪
滅




。




顛狂道德持





。




高眀常鑒照




。




方寸欲何之




。





獨立關情意




。




鏘洋合古今




。




推遷閑歲月




。




未洽庶民心




。




碧照浮空色




。




紅分次第深




。




景風聽
有韻




。




盡入
舜絃琴




。





自古證於今




。




思量事轉深




。





公私千定日




。




真偽萬般心




。




富貴驕貪失




。




榮枯豈
易尋




。




姦邪終不久




。




君子尚難任




。





為人能省己




。




就靜亦皆忙





。





春去秋來定




。




年諸日遠長




。




英姿終有異





。




賤品足顛狂




。




蠢動
含靈性




。




善生惡
自亡




。





無窮思廣大




。





幽隱便知深




。




智達千經論




。




方關一寸心




。




聦眀懷往古




。




曩刧順從今




。




此理人湏信




。




周旋子細尋




。





御製秘藏詮幽隱律詩卷第二十二



丁未歲高麗國大藏都監奉
𠡠雕造
