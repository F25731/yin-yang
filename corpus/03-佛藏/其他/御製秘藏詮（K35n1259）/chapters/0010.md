# 卷10

御製秘藏詮卷第十　　　　　　　車





義解無生智




。




無生智不來




。




非智亦非解




。




上智豈能開





。





起徧知心識




。




六情何足戀




。




一燈然百燈




。




恒作法輪
轉




。





法教世尊說




。




慈
觀大化身




。




𠃵坤皆徧照




。




得達渡迷津




。





旨趣高千億




。




花開有舊新




。





山河及大地




。




鄙我利他人




。





玄閫難知盡




。




熙然大法身




。




窮之不可
極




。




筏渡愛河津




。





疑執無邊際




。




不疑却自見




。




清淨苦海間




。




明
月光如練




。





幽化𠃵坤外




。




逍遙道可貧




。




邪宗難間隔




。





慈眼視相親




。





大哉調御力




。




廣法混穹旻




。




無
執非常說




。




非因即是真




。





信施及天下




。




終依塔廟親




。




眾
生具佛性




。




智識定人倫




。





興善求諸佛




。




妄緣自不見




。




眼前黑闇中




。




此法如霜霰





。





智超雲水淨




。




絕影亦
無塵




。




妄相迷途隔




。




終為不悟人




。





我聞如是說




。




不達謾勞神




。




及見無言盡




。




茫然無所親




。





真本清如水




。




濁緣豈得親




。




常如眀智者




。





甚處有艱辛




。





念悉信無常




。




修行興大善




。




慈
心起大悲




。




但鄙貪癡戀




。





慧性歸元化




。




綿綿若守真





。




有無通性相




。




解了自清神




。





說亦真常道




。




妙果論祇園




。




能成
諦信事




。




寂靜本因言




。





理究真空理




。




慈悲号世尊




。




湛然
虛妄境




。




魔眾靜無諠




。





恒星不見時




。




我佛行方便




。




金鑛混精光




。




成後終無變




。





詮緫如來藏




。




清流萬法源




。




隨情登覺道





。




何用使心權




。





求利他人益




。




玄談不可論




。




真如常不
動




。




經重法王尊




。





解即非常見




。




其中事鄙煩




。





不能隨境變




。




容易過朝昬




。





習性盡由心




。




愁人不自鍊




。




如珠走碧天





。





所在得圓轉




。





證悟無生事




。




禪波潤法門




。




人心自不定




。





邪浪逐風喧




。





志極恒沙界




。




廻邪起妄
言




。




纖毫俱不是




。




寂靜豈知元




。





果報分眀定




。




應同野馬奔




。




百川歸大海




。




難
辯舊波痕




。





除假要歸真




。




魔心終是戀




。




因緣性亦空




。




法共恒沙轉




。





因中洪水大




。




驚波濁浪渾




。




無心風自
止




。




清淨理歸源




。





義遠諸天眾




。




情迷白日昬




。




如來傳秘
教




。




愚見與誰論




。





法偈周遷徧




。




任從經百千




。




菩提真是果





。





萬代劫中傳




。





想念情中實




。




如露亦如電




。




端
坐利羣生




。




無剎佛不現




。





達意忘虛幻




。




玄機有後先




。




一言如道合




。




超證自
依緣




。





玄寂非無相




。




先袪有妄緣




。




根塵
能泯滅




。




金地見青蓮




。





幽巖修道行




。




為事信天緣




。




無
來兼不去




。




誰後復知先




。





俗網障菩提




。




非論今與昔




。




當知釋氏尊





。




慈慧
常光弈




。





大恩施不報




。




小惠豈拘牽




。




平等悉無礙




。




迷
情免縛纏




。





信之不可及




。




貪欲自招牽




。




因緣皆種得





。




何事豈
遷延




。





智不周旋盡




。




寂空次第圓




。




剛柔知用利




。




妙道亦如
然




。





諦信便知因




。




有方行利益




。




隨緣受果
報




。




定至寶山積




。





我欲救諸苦




。




眾生執妄緣




。




業因不可救




。




諸聖󳯝相
宣




。





真心不可測




。




無黨亦無偏




。




慧偃隨風草




。




非唯逐
境遷




。





慧為智所轉




。




智慧妄隨緣




。




無智復無慧





。




真心自寂然




。





語意說分眀




。




其言無間隔




。




法心是本緣




。




冤債如
冰釋




。





說果皆因種




。




勿疑虛自勞




。




天堂與
地獄




。




終
不隔纖毫




。





理長終入妙




。




雅淡寂風濤




。




可信如來說




。




徒言
智識高




。





詮言非敏󲖕




。




未必滌塵勞




。




不曉開心印




。




寧誇智慧刀





。





言語因成道




。




是非歸化寂




。




津梁行在世




。




福
業緣中得




。





求言通達識




。




言話意須高




。




佛理都無著




。




眉間
放白毫




。





解種千生福




。




戒隨剃髮刀




。




諸冤兼妄語





。




終滯業
心勞




。





證驗僧祇刧




。




飄鼓信風嘷




。




江河雖注浪




。




洪水自滔滔




。





純一更無雜




。




真空光照出




。




殊途皆體用




。




清淨
十方力




。





御製秘藏詮卷第十



乙巳歲高麗國大藏都監奉
𠡠雕造
