# 卷26

御製秘藏詮懷感一百韻詩卷第二十六𦘺





一統𠃵坤順太初




。





照臨無外越唐虞




。




樂推大定
聲聞遠




。




𦗟斷無疑自卷舒





。




化導隨時彰覆載




。




周通利物混車書




。




唯
慙寡昧齊堯世




。




深愧󳏧言頌帝居




。




端拱未知何所措




。




招賢󵦮念慮
関子




。





常持警誡綏仁惠




。




運偶承平免負芻




。




區別動來敷教令




。




庶幾閑暇少
縈紆




。





千峯路險非三島




。




一󰏯輕舟泛五湖




。




分𣲖長流丕祚永




。




寰瀛相踵別親踈




。




姦
欺己塞根源盡




。




暴虐潛消蔓
草除




。





才業所高歸汗渙




。




賞功何恡借吹噓




。




狂心屏跡皆依度




。




率土咸寬𭣼下愚




。




憲法逈然摧狡蠹




。




公平俄
見辯精󱍮




。




淳和已變澆漓態




。




奔競還
知禮讓趍




。




庶𦒳漸營鄉巷陌




。




守臣無事
訟𨓍虛




。




願聞
唘沃同韶護




。





至理忠貞𢙣諂諛




。




純直但能酬雨露




。




矜持必可離差殊




。




升高目下存卑
小




。




捨短從長入奧區




。




赫弈明然欣世俗




。




希夷道泰握𠃵符





。




優容儼雅周通濟




。




鄙陋󳭪張作教敷




。




等級󳯝遷崇厚德





。




豈遑安
處用相拘




。




端莊盡善
延鴻福




。




返朴終期立楷模




。




成敗誰知容易失





。





安危美譽甚難乎




。





焦勞不避千年日




。




救苦如烹萬億爐




。




去就若恒持耿介




。





遠傾竭節是良󲅭




。




但憑直道來干祿




。





莫遣回邪用巧謨




。




訓
誥恬然更不法




。




品提
自覺有均輸




。




昌朝畏愛懲
貪吏




。




我代銓衡委大夫




。




主聖當因思獵渭





。




臣驕未必擊珊瑚




。




神光夜燭崑
山玉




。




璧月霄分合浦珠




。




縹緲恒沙搖碧
落




。





霏微雲雨潤紅蕖




。




花飛起樹驚幽鳥




。




水壓清天看躍魚




。




北
闕󲰥兵精騎射




。




南方下水伇征途





。




德音湯󱶈
開三面




。




拯溺𥟦甿樂四隅




。




稟奉朝儀修軄貢





。




觀
瞻景象駕乘桴




。




秦川菓熟思鸚鵡





。




澤國春殘詠鷓鴣




。




域外縱
情閑隱逸




。




村中皷腹唱樵漁




。




陶鎔鼎鼐
窮玄奧




。




軓範人
倫絕覬覦




。




爽氣調勻身力健





。




陰晴蕩颺鴈相呼




。




千尋
樹影光煙彩




。




一片江山入盡圖




。




野客信緣離島
嶼




。




經商㸦往汎荊
吴




。





辤家勿慊盈襟淚




。




銜命兼騎內廄駒




。




萬里迢
遙程迆邐




。




九疑高嶮路崎嶇




。




解將省己應難
得




。




多是群迷䧟薄徒




。




遠占松蘿森澗
谷




。




道成鶴骨
瘦肌鬳




。




遐荒辮髮懷鄉土




。




畎畒分溝掉轆轤




。




城壘澷令空抵擬




。




関防恩重不支梧




。




詩書禮樂清寰宇




。




道德興來任魯儒




。




和睦紀綱皆𭣼肅




。





均平長養致歡娛




。




禹征有扈功難比




。




舜格苗民
用意驅




。





御製秘藏詮懷感一百韻詩卷第二十六



丁未歲高麗國大藏都監奉
𠡠雕造
