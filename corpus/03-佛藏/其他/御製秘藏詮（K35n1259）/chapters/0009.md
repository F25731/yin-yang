# 卷9

御製秘藏詮卷第九　　　　　　　車





旨趣知深淺




。




來傳自域中





。




祇園修本行




。




功妙果無窮




。





玄義皆殊勝




。




真源是實宗




。




一言能
悟解




。




萬法自圓通




。





幽隱分眀說




。




筌蹄覺妙通




。





萬緣皆𢍆合




。




佛行弃王宮




。





有為不挂情




。




如見示深信




。




帝
釋與梵王




。




諸天論五印




。





大覺無涯海




。




慈悲慧眼雄




。




眾生能
信受




。




達識盡為空




。





信施身財寶




。




灰心一念中




。




真如無別理





。




極際
杳玄穹




。





知本元非用




。




因緣
假合同




。




古賢宗實相




。




草偃盡隨風




。





情欲皆人願




。




時間心逆順




。




咸觀玄
悟音




。




師子能奮迅




。





我為眾生故




。




開張一貫通




。




金
言翻不盡




。




像教集如宗




。





真理𡨋心悟




。




無疑大化中




。




世間聡慧者




。




夢𥧌想
來空




。





慧奧雖微細




。




湏歸道理通




。




世緣無取捨




。




必定
離昬蒙




。





喜不挂情懷




。




法終歸善願




。




若非智慧
方




。




真言垂億萬




。





說佛因緣智




。




諸邪勿強知




。




忻心
常淨潔




。




所在不思議




。





理徑逍遙遠




。




何能委曲知




。




攀緣俱是夢




。




清淨入無
為




。





詮義歸諸聖




。




如常道不虧




。




若能消妄想





。




孰是斷忘機




。





迷因心地起




。




不解承慈訓




。




功行自遷
延




。




常疑非大信




。





求佛歸三寶




。




㽵嚴道不違




。




自然精法用




。




善事好相依




。





悟解真如理




。




無他絕是非




。




端嚴依
實相




。




萬慮寂然歸




。





證善推因果




。




功圓道不虧




。




悲心恒及
物




。




報應
又何疑




。





失意墮阿鼻




。




聖賢無所恡




。




常
行平等心




。




在處皆精進




。





志滿三千刧




。




修行十二時




。




但除人我見




。





可認大慈悲




。





果因圓似月




。




善願離諸非




。




報應心地得




。




斷絕勿狐疑




。





因緣𠇲妄捨




。




清淨𢍆玄機




。




不把
心求識




。




怡然眾聖知




。





捨施就慈悲




。




因中彰法信




。




大千世界空




。




穀麦皆滋潤




。





覺悟迷途寂




。




眾生奉法時




。




諸天乘福力




。





䪺證涅槃機




。





法印流東土




。




因從像教初




。




三乘真旨趣




。




妙覺大千舒




。





旨趣高人解




。




先賢道不殊




。




經傳四大國





。




迷眾
出凡途




。





若薦諸緣業




。




非情堪讚歎




。




自身求果
報




。




光聚
眀中散




。





玄默澄諸海




。




清風蕩碧虛




。




華嚴揚聖教




。




聽法禮
真如




。





幽玄周復始




。




至道化諸愚




。




湛寂眀中外




。




詮源任卷舒





。





大慈悲忍辱




。




妙道入虛無




。




諦剎分
眀照




。




圓光盡樂胥




。





道願常精心




。




狂迷怠墮漢




。




不於內外求




。




賢聖慈悲看





。





信施門方便




。




功德一何殊




。





寂心人不昧




。




摩尼轉寶珠




。





智能圓萬德




。




利樂報湏臾




。




菩薩權真實




。




慈恩
信有孚




。





我法傳於世




。




因緣定不虛




。




能修無上道




。




真味有何殊




。





福慧廣精嚴




。




𡨋心拱手看




。




如來渡法舡





。




定相觀
迷岸




。





真空行利益




。




妙用極虛無




。




彈指中間
事




。




方
圓自有餘




。





慧炬分眀照




。




昬迷道坦途




。




四生及九類




。




利益徧
寰區




。





說法行方便




。




靈山四眾來




。




親
聞如是說




。




福業洞然開




。





業海起風濤




。




真心非頋󱌁




。




人心自不眀




。




罪福聲相喚





。





理滿閻浮世




。




功超百萬
垓




。




但能知善𢙣




。




海岳納㳙埃




。





詮演真如理




。




歸元達辯才




。




無
為中妙旨




。




足下碧蓮開




。





求真非念佛




。




善路涉靈臺




。




但除心邪
想




。




何
憂業不摧




。





違善投於罪




。




非賢道不見




。




妄求終是迷




。




法電光流轉




。





解空真我士




。




形㒵有輪廻




。




地獄天堂上





。




慈
悲事可哀




。





證道歸空理




。




澄心道不乖




。




根塵俱斷染




。





喜願自盈懷




。





自利他緣起




。




威光去復來




。




無疑皆自得




。




諸法信心咍




。





順即達菩提




。




逆時終不見




。




本來
萬法空




。




豈在矜誇炫




。





果願從因起




。




因成果自來




。




無因又無
果




。




因果向誰開




。





因性緣上得




。




緣還性亦來




。




無心亦無性




。




心性可哀哉




。





御製秘藏詮卷第九



丁未歲高麗國大藏都監奉
