# 卷23

御製秘藏詮幽隱律詩卷第二十三　𦘺





皆救眼前急




。




錐刀蘊利名




。




愚心違善道




。




慧眼自分
明




。




大海波浪
沒




。




深山棟木成




。




旁求存古意




。




後學法先
生




。





天地𢙣諸盈




。




良賢蘊盛名




。




折旋知俯仰





。




進退
有嘉聲




。




自料皆冝靜




。




非言事莫輕




。




輸他依法度




。




寡譽亦無成




。





宣𡰱明有說




。




德行㝡為先




。




純厚皆垂慶




。




芳名信古傳




。




在家思孝義




。




食祿斆英賢




。




具載光經史




。




仁風樂舜絃




。





知淺復知深




。




先賢不
尚爭




。




誡貪興有利




。




無事保長生




。




物性三
才逈




。





幽通萬象清




。




但教依法度




。




積善響佳名




。





壯年勤且樂




。




暮齒免
荒凉




。




有路撗霄漢




。




英風自蘊香




。




湖中明印月




。




星碎亦光芒




。




誡懼知盈溢




。




神靈禍不祥





。





庶事情多感




。




光
陰自古長




。




貪癡何意遣





。




愚軰為誰忙





。




紅󰏯隨時變




。




白頭㝡易傷




。




世途能及物




。




善德遠馨香




。





終日窮經史




。




思惟事轉深




。




公忠懷士意




。




是理好相尋




。




聦惠玄
高鑒




。




回邪抂用心




。





從容閑歲月




。




學古便知今




。





一逢又一別




。




來往幾時休




。




處世
皆名利




。




貪生去不留




。




善緣看似夢




。




𢙣事勿臨頭




。




如病
心常怕




。




生前
樂自由




。





爵受帝恩榮




。





英才一德清




。




昂藏真體㒵




。




忠
孝福蒼生




。




武士干戈偃




。




文儒𨦣氣橫




。




盈朝多有位




。




各願
致昇平




。





謙遜明然得




。




滋
章道理踈




。





榮枯皆定分




。




巧拙亦何如




。




撫俗從仁感




。




臨民用教敷





。




高明歸輔
德




。




建立紀功書




。





爽思開清眼




。




看書見古風




。




靜來入深
道




。




廓落意何窮




。




荏苒郍堪久




。




愚癡治不通




。




含生皆是性




。




氣槩壓群雄




。





慵修勤苦志




。




將甚
立於身




。




經史何
窮極




。




文儒慕
好親




。




緣深觀在掌




。




不奈世情人




。




鑒誡無
休息




。




泥
蛙問海津




。





清霄白鶴唳




。




移
步向前看




。





去住高分翼




。




群飛景際寒




。




喜情依碧落





。




極
望入雲端




。




遙
天千萬里




。




方知世界
寬




。





生涯將所用




。




隨分
勿教多




。




敗德因狂酒




。




輕浮猛渡河




。




不欺終降福




。




公政盡輸他




。




獄訟無怨抂




。




民摸治病痾




。





二儀交始結




。




元氣
濁分清




。




浩
渺無涯際




。





陰陽造化成




。




三辰居象外




。




五老隱芳名




。




寒暑相催促




。




人天物誡盈




。





閑心無事外




。




属意在風騷




。




日去還來遠




。




文成壯志高




。




凝情知
道廣




。




拘束轉
焦勞




。




塵世是
非理




。





賢愚有智刀




。





世途含萬象




。




稽古便知今




。




大樹垂清影




。




如花耀碧岑




。




虛
勞空自白




。




德行
勝黃金




。




有過
而能改




。




無為積
善深




。





澄寂都然靜




。




閑披短
褐衣




。




臺
高風爽麗




。




花落鷰銜飛




。




老漸知茶味




。




年逢見
日暉




。




道情深可笑




。




怕酒養
真機




。





愛老及憐貧




。





逢迎善者親




。




道高
明似日




。




世有幾般人





。




盛暑觀
蚊蚋




。




窊
魚探海津




。




閑忙皆自得




。




冬去後
知春




。





舉措皆䂓矩




。




廉能理道通




。




公平高釋意





。





直曲在其中




。




惠化歸仁德




。




周才有
士風




。




更求懷利益




。




品物自冲融




。





世間何所益




。




樂善有馨香




。




貴賤雖差等




。




非違
定不祥




。




春臺冝勝地




。




花木敗嚴霜




。




求取
立身行




。




恒持但久長




。





宮沼澄天水




。




泉分曲直邪




。




有時經暮雨




。




流出上林花




。




逕草連朝霧




。




踈林照晚霞




。




高閑心物外




。




人事樂生涯




。





雅道包玄理




。




人天悉盡通




。




悟真全可事




。




迷昧不成功




。




身外皆
緣寂




。




心閑即
是空




。




常情能自遣




。




豈靜覔山中




。





天降符𡨋合




。




亨然遠
事來




。




揵音邊上奏




。




喜
甚勇聲咍




。




風卷長空
靜




。




雲從景際開




。





軍民欣不已




。




世務益
康哉




。





善事足多魔




。




𢙣緣不奈何




。




生踈無
正定




。





孰究理相和




。




塵垢迷情染




。




經文妙義多




。




信之
含大道




。




真性起煙蘿





。





御製秘藏詮幽隱律詩卷第二十三



丙午歲高麗國大藏都監奉
𠡠雕造
