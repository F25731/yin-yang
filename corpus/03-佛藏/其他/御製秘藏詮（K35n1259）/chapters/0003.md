# 卷3

御製秘藏詮卷第三　　　　　　　車





論教還歸一




。




如來法自通




。




真心無出沒





。




丈六儼
金容




。





去者依諸法




。




來時應亦同




。




未將
虛種𪫬




。





妄想在其中




。





住為如來意




。




無機不可宗




。




涅槃本
寂靜




。




少剩更何容




。





捨業離諸緣




。




無眀如指掌




。




寂然聖道通




。




運化谷
聲響




。





慈心初竪拂




。




賢者可明宗




。




非法
與禪定




。




不
解莫通風




。





悲觀塵沙種




。




誰眀果有功




。




不湏心隔障




。




十地盡因
通




。





譬喻法皆真




。




群生出愛津




。




威儀呈八萬




。




境物不因循




。





𪫬善通三界




。




分眀戒定旨




。




要知法智身




。




真𪫬本如是




。





喻法龍華日




。




從茲妙道臻




。




如來雖不說




。




迦葉悟
空真




。





圓淨如眀月




。




心傳五印文




。




殊
途雖渺邈




。





一理妙中分




。





滿願生兜率




。




區分秘藏文




。




大悲慈忍力




。




萬劫接迷群





。





相好是端嚴




。




觀音行妙旨




。




優曇浩徧知




。




生滅依真理




。





功滿聞知識




。




身貧道不貧




。




豈將容易得




。




邪法妄名
親




。





德道成朝夕




。





昬迷為假因




。




靈源如不動




。




方悟本來真




。





利𪫬本眀了




。




是非多不勻




。




未
能窮二法




。




終䧟向沉淪




。





心達自區分




。




真修無彼此




。




始終了信心




。




應審信心是




。





益認阿含果




。




休論舊與新




。




見時如妄
眼




。




此
事不為真




。





故知心與𪫬




。




二法不能真




。




一證金剛體





。





終無染垢塵




。





顯法云何是




。




徒經秋與春




。




山川雖變異





。




至理盡還淳




。





識上達空玄




。




無心真妙旨




。




其如有暗明




。




悟即聞
斯理




。





攝𪫬亦成難




。




菩提道自安




。




真源雖可寂




。




世法自凋殘




。





受想沉幽谷




。




春秋任往還




。




細推非五眼




。




惆悵自多端




。





化喻豈盤桓




。




還憑智者觀




。





一心非妄說




。




覺海浪澷澷




。





情樂欲於心




。




他緣生表裏




。




寒暄與盛衰




。




苦海無窮水




。





俗士求諸法




。




迷情去不還




。




惡風吹妄筏




。




失却鷲峯
山




。





報果善心攀




。




森羅萬象間





。




不勞心與智




。




道法亦如閑




。





應現非今日




。




精窮六識閑




。




種麻不生麦




。




善願離人間




。





欲達本宗枝




。




深心不暫止




。




無情法甚眀




。




顛倒何
為是




。





成就皆通識




。




迷途離苦艱




。




論情多障礙




。




𪫬相不妨難




。





就利因眀果




。




相隨自往還




。




沉吟無問處




。




宴坐有無間




。





觀處心無著




。




緣情不可攀




。




眀文聖中境




。




清淨
不相關




。





求法有無形




。




貪嗔五惡起




。




玄微
本妙因




。




妄相宗何旨




。





悟法同心合




。




俱通𪫬海間




。




眾生如不妄




。




疑網脫幽關




。





有妙清諸界




。




無緣顛倒疑




。




一真如法雨




。




普潤更無私




。





情爽非聦利




。




色空更問誰




。




若窮深
妙理




。




方信世傳衣




。





願滿亦非常




。




經文隨妙旨





。




唯聞不動尊




。




湛淨達真理




。





喜聞開正法




。




對境慧光施




。




信受如
常法




。




當逢一聖知




。





有𪫬韜三昧




。




終成覺道遟




。




迷人不自信





。




業種䧟
阿鼻




。





取捨情何極




。




不曾拘是非




。




人心多不定





。





正法勿相疑




。





安樂靜皆空




。




斯言深妙理




。




諸非
是惡緣




。




去住無涯矣




。





捨離袪煩惱




。




迷情自不知




。




梵經西域旨





。




真悟破邪疑




。





修進成何法




。




開張百萬機




。




不能心縱逸




。




真偽妙相依




。





道隱人天上




。




逢緣經是師




。




五陰空寂靜




。




觀聖復何疑




。





樂哉諸聖賢




。




人世多憂喜




。




能解作無心





。




欻然千萬里




。





福徧薩訶世




。




非心妄豈知




。




不迷真與相




。




賢聖
盡如斯




。





業境是兼非




。




真常世所為




。




福因知厚薄




。




善惡不相離




。





違行失真機




。




何人悟達之




。




發心多願足




。




終會法王師




。





戒法諭諸因




。




緣從何舉止




。




色空了
妄心




。




攸久還如是




。





順志常平坦




。




違相自嶮巇




。




良緣相接引




。




無上道心知




。





起信多般願




。




經文好仗依




。




法輪
常自轉




。




真聖是玄機




。





御製秘藏詮卷第三



丙午歲高麗國大藏都監奉
𠡠彫造
