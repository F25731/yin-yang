# 卷24

御製秘藏詮幽隱律詩卷第二十四　𦘺





怡閑銷度日




。





取性日高眠




。




恠石臨
𤗉認




。




踈籬枕
水邊




。




琴棊延處士




。




茶煑近山泉




。




倚岸垂楊柳




。




紅花落釣舡




。





何事光天意




。




悠哉豈易窮




。




昇平皆致理




。




亂世自多
同




。





日轉依常道




。




山高聳半空




。




文經書
百代




。




詳酌幾人通





。





歲久胡顏是




。




無過遂
壯心




。




迍邅
皆自作




。




福祿善緣深




。




賢哲遵
依道




。




狂生笑古
今




。




孤根終凍死





。




餓虎困山岑




。





避罪勝修福




。





其為理一般




。




資財豐
利益




。




公
道不欺瞞




。




濁世
貪榮祿




。




眀時
善政官




。




遏強能撫弱




。




容止勢情觀




。





料敵還難得




。




駈馳話戰塲




。




貪殘興造次





。




必受反
灾殃




。




决勝先
眀筞




。




論兵不
下堂




。




精通眀
理亂




。




興替有
存𰀄




。





絕代西施色




。




爭如醜婦人




。





先賢非羙㒵




。




高鑒瑩磨新




。





𧟶國忠良立




。




亡家自起因




。




亂常
皆速禍




。




情偽顯於真




。





地卑生𣗥刺




。




嶺上白雲多




。




君子懷忠信




。




愚迷不止訛




。




妄情終
是昧




。




六道
豈偏頗




。




齋
誡存清淨




。




經聲樂亦和




。





歸客何遅晚




。




秋雲暮亦寒




。




草枯鷹犬利




。




戰馬䥫衣寬




。




儒措真才子




。




英雄俊長官




。





令嚴兼畏愛




。




𦙃吏𣫍容端




。





獨坐自懽娛




。




遊行意不拘




。




端倪撗縹緲




。




談笑斷
縈䊸




。




惆悵思往日




。




徘徊悶卷書




。




澹茶時省睡




。




慵墯轉生踈




。





時世多英俊




。




能看萬卷書




。




更懷知識見




。




理事
遠昭蘇




。





必究師仁德




。




宣揚樂我徒




。




閑忙勞自苦




。




潔白瑩冰壺





。





有智更兼學




。




眼前豈易精




。




風駈雲不定




。




龍闘虎堪驚




。




舒卷臨時用




。




叅差定不成




。




高心由變化




。




布置要分眀




。





石室巢新鷰




。




人心在眼前




。





飛雲高去影




。




敗葉擁流泉




。




取捨憑誰定





。




升沉勿自
專




。




守貧知
大道




。




盛事好
攀緣




。





多言心不善




。




出口莫能追




。




如夢歡娛樂




。




歸家說盛衰




。




擬將
何所用




。




理乱別公
私




。




方寸巧施設




。




小人亦可悲




。





擾擾塵中內




。




忙忙滿路歧





。




思量竆
不盡




。




語默豈能知




。




巧拙從他定





。




縱橫
勢莫移




。




青霄雲
隱沒




。





恬淡得希夷




。





偶入園中坐




。




春風味㝡長




。




花開添
爽麗




。




臺榭不勝芳




。




草茂稀踈得




。




鸎遷語異常




。




暄天和景象




。





智遣有閑忙




。





傍觀經史上




。




楚漢定龍虵




。




豁達寬懷
抱




。




狐疑豈重
耶




。




仁湏歸有德




。




惡意
亂交加




。




嶮易
論根本




。




興亡不用誇




。





落󰏯知秋早




。




寒汀夜月眀




。




是非皆得所




。




澹
素少交情




。




日暮歸何處




。




煙波望遠平




。




逍遙誰入道





。




天大保長生




。





銀屋朱扉曉




。




金󲊷本是真




。




玄華凝顥氣




。




清境
絕埃塵




。




道德山川媚




。




虛無嵗月新




。




猶龍天
地理




。




說與洞中人




。





法演雙林下




。




凡情世眼觀




。




淡煙光
雨際




。




孤月淨雲端




。




意思皆時暫




。




縱橫大教寬




。




含情能息慮




。




物外不相干





。





從前高達士




。




無礙信天緣




。




動達玄
言理




。




眀通造化權




。




容怡
存古道




。




謙退足周旋




。




勿傲清平
世




。




眀時
正用賢




。





行止由修鍊




。




輝光朗自然




。




深山藏虎豹




。




大海隱龍泉




。




鶴唳
冲霄漢




。




龜生得壽年




。




怡情含道
識




。




浩渺九重天




。





顏回真德行




。




陋巷一儒該




。




亞聖門
人飾




。




詩書
孔子才




。





清虛皆是道




。




秘奧演重開




。




幾千年
底事




。




入我
󴁓中來




。





秋信西風急




。





踈墉野性高




。




猶忻嘉雨至




。




就靜不心勞




。




樹色光池沼




。




花逈壓蓬
蒿




。




痛飲
終何必




。




登臨散鬱
陶




。





君子筵樽俎




。




箴䂓話
短長




。




秋深
籬菊晚




。




春盛
牡丹芳




。




隈淡雲
分色




。




情隨日順陽




。




酒斟
任意滿




。




小樂聽
無荒




。





民間天上事




。




通理
一言之




。




仙積千年壽





。




人終百嵗期




。




禮容分
次第




。




𪵬愛別尊卑




。




福業有輕
重




。




𨚗
堪亂作為




。





御製秘藏詮幽隱律詩卷第二十四
