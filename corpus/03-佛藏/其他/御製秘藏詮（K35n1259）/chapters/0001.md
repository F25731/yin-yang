# 卷1

御製秘藏詮序　車

。



粵聞詮源秘旨。



。



隨機立教以興
言。



。



法海
淵深。



。



性相歸空而是說。




。



如來妙覺視現
慈悲。



。



傳祖印
於人間。



。



觀清淨於天界。



。



開諸
妄想。



。



破執迷途。



。



智易三乘。



。



門
通一揆。



。



悟法必茲於頓漸。



。



起信莫先於意遣。



。



玄機默授化導無知之俗。




。



體用垂方安隱昬衢之𪫬。



。



況乎威靈控御。



。



像教崇虛。



。



湛然
典憲於十方。



。



賢愚俱臻於萬
彚。



。



微言廣被。



。



救濁世於三千。



。



遺教自然。



。




想端嚴於四八。



。



敷揚正法
宗闡甚深。



。



非大智者無以窮其
源。



。



非達識者莫能知
其要。



。



包括殊異。



。



奧義遐宣。



。



有
相之情皆空。



。



無生之滅皆寂。



。



幽深道遠求之
者不可得其中。



。



報應必通究之者弗可曉其理。




。



貫穿德義。



。



法相㸦陳。



。



窺解脫於毫釐。




。



較優劣
於性識。



。



蓋
為㕘演經論設彼紀綱。



。



形言於竹帛之閒。



。



致理於凡聖之內。



。



慧日照臨於碧
落。



。



柰苑
騰芳於善根。



。



列智炬之光。




。



願發有情之相。



。



破重昬之境。



。



󳇐慶無礙
之因。



。



覺熖之燈長眀。



。



幽闇之室恒顯。



。



閶闔銀𨷂教諭
金文。



。



棲息煙蘿深巖秘密。



。



扶持依仗於佛慧。



。



塵劫永曜
於蓮宮。



。



歷世常鑒於高眀。



。




攸久混同於天地。



。





御製秘藏詮卷第一


佛賦二首附
謌行一首附



性法光常照




。




如來大戒儀




。




修
行功德業




。




攝受智心持




。





相滅空千刧




。




真純絕是非




。




善心興一
念




。




性靜法王機




。





心達無邊境




。




虛空入
有微




。




見今過去佛




。




性相寂空歸




。





譬喻法如常




。




求多心自了




。




世尊演上乘





。





四眾瞻圍繞




。





識用攀諸聖




。




經
緣道本基




。




愚癡貪自縛




。




福業各相隨




。





情狀如萌發




。




精嚴好仰
依




。




因緣菩薩種




。




順悟逆相違




。





欲量無邊劫




。




其如業力癡




。





信中能妙解




。




赫日爍冰池




。





喻性本來眀




。




法天心是道




。




達時悟有緣





。




諸聖
開懷抱




。





求福還如夢




。




性通慧不知




。




是非身
法相




。




殊勝若何為




。





願樂與精進




。




二途俱妄為




。




無機誰辯別




。




撈月海中
迷




。





安心袪妄想




。




烏兔豈能隨




。




一善性中得




。





貪緣去莫疑




。





圓果利皆通




。




心關方寸了




。





清涼逢世住




。




甚處有煩惱




。





樂善證菩提




。




真空瞥
見時




。




不為眼所著




。




誰肯逐狂
迷




。





戒律自持秉




。




人心無了期




。




莫將因果比





。




清
淨不思議




。





定性歸何趣




。




真宗事不迷




。




法身無所得





。




愚
智有高低




。





滿月似金容




。




因緣隨相好




。




但無
人我心




。




觀見真如道




。





釋了還依舊




。




經言理不虧




。




千穿與
萬鑿




。





求取果圓時




。





意欲求諸法




。




真心不阻違




。




到頭湏是實




。




色相自生疑




。





經教不通理




。




疑緣獨是非




。




大巧與大辯




。




終不妄施為




。





功行四周天




。




威光無不到




。




寂心本是空




。




真正降
邪道




。





論法尋常是




。




真空好仗依




。




如來因
地厚




。





清淨本無機




。





去來何所得




。




果證不參差




。




大樹深根蔕




。




非
緣豈可知




。





住見輪廻定




。




桑田變海涯




。




年從
經劫減




。




果報盡相隨





。





德廣徧羣生




。




慈悲懷節操




。




不
拘前後際




。




無著亦難討




。





慈心如不動




。




方寸自東西




。




性種常清淨




。




無令意
馬嘶




。





悲智羣生類




。




終無識法為




。




業輪常自轉




。




六道甚棲遟




。





性海理無邊




。




堪傷像法遷




。




如來慈忍力





。




舉手向青天




。





利益及三界




。




日光明佛道




。




普照無
邊方




。




能破諸煩惱




。





相引無邊義




。




還迷不省緣




。




悟來隨旨受




。




真實本如然




。





心境求緣識




。




推之遠更遷




。




非論修與
證




。




達性自周圓




。





識細恒沙界




。




經雄滿大千




。




光明臨
世俗




。




譬喻說無邊




。





益彼惠生民




。




勿憂登聖道




。




一麻兼
一麦




。




慈惠恩施好




。





情妄皆非正




。




紅蓮淤水鮮





。




有情俱是相




。




威力等無邊




。





欲逼諸煩惱




。




非因信所牽




。




未通一法理




。




甚處得周旋




。





求即剎郍得




。




聦眀智自然




。





微中玄妙聖




。




性海量無邊




。





故知不可說




。




悲願貪生老




。




從此四門
開




。




菩提成大道




。





願我無為法




。




縱橫徧大千




。




光眀如皎日





。




慧眼照
人天




。





安樂功殊勝




。




谷聲聽
郍邊




。




不
求還自見




。




似對法王前




。





樂道心安泰




。




如山擁在前




。




法雲常寂意




。




日月自恒圓





。





顯教極閻浮




。




昬衢多不了




。




幽眀難測量





。





眾生自懊惱




。





戒說僧尼律




。




捨身離俗緣




。




非求真境界




。




一法二空
前




。





定觀為何事




。




未曾道理偏





。




靈山知有佛




。




性識本如然




。





釋教無虛妄




。




高明大法天




。




眾生能
見性




。




我亦不能宣




。





攝認及諸邪




。




如來方宴坐




。




真心大道
空




。




誡忌於人我




。





意求佛與法




。




五蘊理空玄




。




萬法皆歸一




。




慧解障心圓




。





經演法王前




。




分明句偈傳




。




當時
曾了達




。




信受度金僊




。





論證無生理




。




修持想郍邊




。




不如休去住




。




靜坐化人天




。





受報諸因緣




。




聖言不可捨




。




我心常湛然





。




誰
當真般若




。





去妄極無邊




。




如其業力牽




。




眾生能得性




。




䪺減
苦纏綿




。





住果隨人願




。




還如植福田




。




善根頻
灌溉




。




滋潤積周圓




。





御製秘藏詮卷第一



丁未歲高麗國大藏都監奉
