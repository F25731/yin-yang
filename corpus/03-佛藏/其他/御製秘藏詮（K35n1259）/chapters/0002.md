# 卷2

御製秘藏詮卷第二　　　　　　　車





慈本因從善




。




但能棄𢙣緣




。




如人
渴飲水




。




冷暖自相便




。





化演深微妙




。




諸天及地下




。




端然
念實心




。





得見真無假




。





悲苦極無邊




。




人心至法天




。




清
涼一境界




。




四眾悟為詮




。





性本不搖動




。




詮禪理究玄





。




真
如常寂默




。




世路認迷源




。





相寂一乘法




。




敷揚說世尊




。




周廻含萬
象




。




𢍆理是真門




。





俗態妄中生




。




非論人與我




。




法憂迷
者心




。




自
󲇊無眀火




。





心明能洞達




。




了義理何煩




。




攝受開
真境




。




智通大法門




。





識見高談論




。




浮榮去若奔




。





聖賢方便智




。




道覺不迷昬




。





情田寬坦蕩




。




迷智鎮常昬




。




不達無生
果




。




因
將甚處論




。





報應定無疑




。




有因及證果




。




本來絕妄心





。




何以立名我




。





欲心如意識




。




清淨滅囂
喧




。




自
有無生見




。




詮源浪不飜




。





求解因心智




。




知非萬劫存




。




先湏恒利益




。




後見法中尊




。





願發因中果




。




慈悲智慧門




。




三
眀達四眾




。




曩劫事空存




。





應現實空相




。




無關亦不鎻





。




玄
途何阻隔




。




佛說端心坐




。





安靜深知道




。




袪非十善存




。




菩提真實相




。




安樂定迷
昬




。





樂境歸空寂




。




無緣有日存





。




求
之不可遇




。




心悟大開門




。





戒定為常識




。




妙音骨目寒




。




法因劫不壞




。




人世自多端




。





成道證無為




。




增超復不墮




。




欲達自縱橫




。




一粒生千顆




。





定入無邊界




。




玄中達者難




。




法通真諦理




。




名利絕心安




。





釋經兼解義




。




立意信多端




。




敷座
眀中覺




。




摩訶𪫬自看




。





意欲求何法




。




迷情似海寬




。




用刀截智水




。




智水
沒痕瘢




。




就大小皆空




。




興心一念果




。




刼常轉法輪





。





境界伏人我




。




經說人天相




。




湏󳇐七寶山




。




不知心是佛




。




善𢙣隱其閒




。





論法超塵界




。




迷情色相關




。




心中疑未了




。




得不大慚顏





。





去聖作何用




。




浮生一向間




。




迷開心得悟




。




萬法鎮常
閑




。





觀世示方便




。




登山見七寶




。




莫教
空手廻




。




智海無心道




。





住法存心想




。




精修一念間




。




莫將果
是相




。




妄見不能攀




。





慈惠人中見




。




無情火亦寒




。




深源清淨水




。




迷濁了時間




。





悲智大慈忍




。




因緣去不還




。




若窮玄寂
理




。




勿使妄
情關




。





見法不言法




。




菩提登覺道




。




差之方寸間




。




真境何
年到




。





性住他方際




。




真言法是空




。




眾
生求自利




。




盡在有無中




。





相合成虛幻




。




終歸一信中




。




如
來宣秘密




。




劫盡始皆空




。





心真非學得




。




施為在法中





。




誰人能
稽首




。





禪定闡宗風




。





有相及無情




。




天堂有路上




。




是
知一切法




。




不可言虛妄




。





識鑒高奇量




。




巍峩大法雄




。




未嘗捐
一善




。




種相徧皆空




。





情戒虛無欲




。




經文所說同




。




端然
恒自悟




。




三界一塵中




。





欲本從人性




。




其如信自通




。




圓光徹宇宙




。




非住五眀中





。





情不動心田




。




眀真除妄想




。




萬般證法緣




。




月現青
天上




。





求益終無󰡷




。




言西語作
東




。




難名生變易




。





真智不通容




。





願知一切法




。




真法自優隆




。




萬境
隨心轉




。




迷情了自通




。





安住絕他意




。




慈悲即是空




。




眀燈袪暗室




。




義果定相逢




。





喜本無顛倒




。




忘形及有像




。




心同皎日眀




。




眾聖堪歸仗




。





樂土亡諸識




。




深沉性海空




。




萬緣方便智




。




隱現是非
中




。





戒行眀聦慧




。




能知業障空




。




勇心精進
猛




。




善願
許從容




。





定相光真境




。




何依住有功




。




三乘俱得理




。




我佛性皆通





。





性逐無眀起




。




昬迷障淨朗




。




妄涌千波起




。




𢙣
業隨緣往




。





釋見全難入




。




愚癡信是聾




。




五音尚有障




。




何得智心通




。





意眀疑有悟




。




萬億豈相通




。




邪見他心妄




。




如來性不逢




。





經說縱橫義




。




千歧
萬沠通




。




一塵如質礙





。




形影兩何從




。





取意性相非




。




人天諸聖像




。




心
忙至理閑




。




未達如波浪




。





御製秘藏詮卷第二
