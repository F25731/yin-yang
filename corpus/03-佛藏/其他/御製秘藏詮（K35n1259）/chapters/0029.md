# 卷29

御製秘藏詮懷感一百韻詩卷第二十九𦘺





醴泉平地湧




。




神雀半空翔




。




內廄縻龍驥




。




瑤池
浴鳳凰




。




五風恒作則




。




十雨競悠颺




。




閭巷皆歡恱




。




歌吹盡不妨




。




輕雲遙󳱬󳱬




。




非霧起蒼蒼




。




比
屋千家樂




。




開扉眾顯昂




。




梅鋪村社白




。




柳映御街黃





。




荷
寵㱕藩閫




。




迎恩會𨶩閶




。




雕題來請吏





。




獫狁定賔王




。




洞府籠
仙署




。




靈椿壽帝鄉





。





蠻夷㱕至德




。




制度法成湯




。




曲沼垂鈎餌




。




清
波躍鯉魴




。





晴軒流月影




。





踈檻透清光




。




武庫森
戈㦸




。




軍容尚繡裝




。




觸邪嚴獬豸




。




啟悵列星郎




。




寓目忻時泰




。




怡情喜歲穰




。





和羹思鼎鼐




。




奏樂飲瓊漿




。




解凍興東作





。




瞻雲望北邙




。




輕傜寬賦稅




。




美景度炎涼




。




擅武施
三令




。




崇儒順五常




。




直誠無
妬忌




。




舉步蘊行藏




。




春滿皇州麗




。




花繁上苑芳




。




閑情資覆
燾




。




有智靜関防




。




敗虜捐車帳




。




戎渠𮨇耳璫





。





鷰歸知社近




。




󲠙化
夢猶㽵




。




聚
落安𥠖庶




。




通才莅事強




。




封陲寬蕩蕩




。




生植茂牂
牂




。




壟畒堆紅腐




。




桒榆勝綠楊




。




書紳無彼
此




。




揖
讓盡鏗鏘




。




世反純和理




。




官清離賄贓




。




平原先畎
澮




。




拒轍信螗
蜋




。




恬淡無高下




。




因緣任短長




。




幽禽捿澗谷




。




寒󳒙度瀟湘




。




野逈胡塵滅




。




年豐積貸粮




。




端珪朝太極





。




道化鎮中
央




。




悖亂知迷惑





。





修持免咎殃




。




漁樵
忻樂業




。





吳越㸦交商




。




禁暴窮
兵筞




。




尊
賢養國庠




。





田多論萬頃




。




食足重千箱




。




堯聖何儔疋




。




舜聦豈
等量




。




守文明肅晏





。




息戰弭旗搶





。




下俚饒分謗





。




中庸
在審詳




。




掖𨓍霞燦燦




。




宮
沼浪泱泱




。




鵬翥三清路




。




鴻
排一字行




。




飛書搜草澤




。




恤物勸農桒




。




報應隨名在





。




施為善否臧




。




天高歸宇內




。





糓稔絕飛蝗




。





玩好空臺榭




。




賢明󳑧陸
堂




。




是非
難可究




。




安
健免󶻈尫




。




立譽湏兢慎




。




𡨋蒙出定房





。





御製秘藏詮懷感一百韻詩卷第二十九



丁未歲高麗國大藏都監奉
