# 卷6

御製秘藏詮卷第六　　　　　　　車





蓬轉緣何事




。




非能比樹高




。




無窮
不解義




。




束手豈能操




。





去住有無形




。




禪僧傳六祖




。




真誠是道塲




。




一切能堅固




。





蓬萊凢草質




。




林木莫知高




。




自是
本情物




。




愚懷一等褒




。





昬暗人知覺




。




緣來氣味香




。




頓
超無上果




。




戒定慧昭彰




。





智益甚深理




。




三途不可量




。




豈
能窮道性




。




暗想願無方




。





住法不思量




。




圓光世所覩




。




端
嚴智慧門




。




救度無常苦




。





香界如山岳




。




圓周大吉祥




。




三天示
法信




。




濁世有清涼




。





風起心中火




。




四天欲簸揚




。




三光無變相





。




花
卉自芬芳




。





中外妄謌揚




。




無人識義方




。




凢夫
說我見




。




終不解施張




。





慈妙大悲心




。




惠施如法雨




。




迷情含
垢根




。




功德難勝舉




。





天人常快樂




。




福慧等無疆




。




不獲摩𡰱寶




。




還憂失妙光




。





精懃無懈惓




。




不憚度炎凉




。




若達菩
提境




。





清心是道塲




。





嚴飾威儀像




。




龍天百寶裝




。




不能光妙用




。





無色亦無香




。





悲感諸天龍




。




信行調御主




。




常持般若心




。




大救六
情苦




。





蘊界設壇塲




。




重宣大法張




。




明珠
相涉入




。




交㸦映靈光




。





陽烏出海面




。




湏󳇐照耀光




。




普見十方界




。




真空示法王




。





俗阜民知善




。




修行業
不生




。





能窮寂滅法




。




靜慮泯浮名




。





修道求根慧




。




乖為成妄想




。




欲知無上
真




。




還同明鑑像




。





諦信如來果




。




精嚴妙解成




。




當仁能體用




。




真相廓然清




。





語解因緣聖




。




眾生用不平




。




萬緣徒
坦蕩




。




一性自圓明




。





言用精窮當




。




詮源道理深




。




功成無障礙




。




種果一般心




。





道合萬緣心




。




五天皆信仰




。




無如我世尊




。




法妙玄中象




。





純性自通靈




。




澄源不暫停




。




欲知迷悟
事




。





萬象本無形




。





和順如來教




。




敷揚妙義成




。




通流無𦊱
礙




。





何用巧經營




。





迷妄如冤賊




。




貪饕意不平




。




三祇無出日




。




魔境
若重城




。





福慧与諸緣




。




金容不動想




。




千聖
證菩提




。




達處無虛往




。





津涯誰測度




。




迷妄轉分明




。




不洗心
中垢




。




如何法海清




。





塵障無明界




。




凢夫起妄情




。




昏迷不覺悟




。




何處達無
生




。





垢惹塵中境




。




因緣自作程




。




離猶分別力




。




煩
惱出無明




。





業通三世足




。




福報甚高廣




。




普蔭及
無邊




。





威容光坦蕩




。





往者是非有




。




迷流濁不清




。




源深千萬刼




。




教法
喻愚情




。





來去真空相




。




虧盈日自明




。




飛塵不駐
目




。




慧妙覺無生




。





人相眾生相




。




善緣離業情




。




利他如不絕




。




淨
土理分明




。





違順起於心




。




何先及有後




。




正真自徧知




。





無縛離塵垢




。





種種他心化




。




依經道理行




。




無情而
善用




。




妙道覺縱橫




。





東土多緣境




。




無生及有生




。




人心知識
用




。




善道惡根平




。





西梵語音別




。




真傳妙聖經




。




法流心普受




。




靜
念境中𦗟




。





順明道不晦




。




大聖觀音柳




。




法界本來空




。




非摧亦非
杇




。





賢者非愚見




。




精通不礙明




。




迴心能忍辱




。




利益
並頭行




。





愚夫興妄念




。




迷想道無心




。




不識
真機要




。




幽玄豈見深




。





舒毫光世界




。




六度十方明




。




俱寂是非相




。




殊功大
法成




。





起信達經義




。




能真誰得久




。




凢夫信不及




。




妄飲
無明酒




。





萬卷盡金文




。




龍宮海藏盛




。




觀音
神妙力




。




一見法長平




。





疑礙涉真境




。




迷真滯不流




。




法常增性識




。




達道本精
求




。





寤寐常存想




。




湏歸教法求




。




聲聞及戒定




。




懺悔信
中修




。





疑水諭迷情




。




方圓隨器
受




。





福緣不可陳




。




業力無邊走




。





知見真心受




。




非言瞑目愁




。




鈍根聞必
怖




。




聖種好依投




。





非佛精嚴聽




。




其餘不足求




。





欲貪無上法




。




悟即妄心休




。





江河與大海




。




一性万般流




。




要識如
來法




。




應湏向此求




。





興善歸真趣




。




成非現好醜




。




法中無穢淨




。




一切復
何有




。





御製秘藏詮卷第六



丁未歲高麗國大藏都監奉
𠡠雕造
