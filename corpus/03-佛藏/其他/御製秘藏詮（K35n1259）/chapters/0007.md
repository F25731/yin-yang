# 卷7

御製秘藏詮卷第七　　　　　　　車





海能來百谷




。




不必海心求




。




自是
緣依法




。




㳙㳙入細流




。





逐業眾生性




。




精持為本
修




。




無心
能自曉




。




宴坐任優遊




。





伏弱通心識




。




慈悲入定修




。




默時還自在




。




妙覺本玄幽




。





念念善無為




。




萬緣歸本智




。




無
言宣諦信




。




非
一亦非二




。





蓬茅方丈室




。




寂坐獨
清幽




。




白日無昬
曉




。




華
嚴次苐修




。





蒿並芝蘭秀




。




如何一類求




。




真空與妄相





。




清濁各分流




。





昏夜至明曉




。




賢皆遇本修




。




誰人能了達




。




三界
徧周遊




。





恒有真常理




。




龍華宣諦義




。




聽徒圍繞時




。




法藏甚深秘




。





垂象分眀見




。




眾生業滯流




。




西天諸
祖位




。




法印不難求




。





香剎無邊際




。




󳇐陁作勝遊




。




寶階三道
上




。




千聖不能求




。





風輪通地界




。




我佛濟慈舟




。




迷悟魔懾伏




。




三天得自由




。





習性自天然




。




眾生能信施




。




真心向佛前




。





願降他緣智




。





中國華言別




。




西天梵語収




。




世尊成道
日




。




龍象瑞光浮




。





天上與人界




。




輪
王法普周




。




四天隨印受




。




聖教闡無休




。





精潔奉香火




。




真緣作妄求




。




十方調法
主




。




瞑目法長流




。





除惡貪嗔緣




。




諸經無不備




。




海波求湛然




。




法眾皆靈異




。





嚴餝威儀法




。




觀瞻恐不周




。




大慈開聖智




。




普為
度迷流




。





陰魄逐波流




。




江河豈暫休




。




慈光廻一
照




。




影像暗相投




。





陽熖影空浮




。




化龍妄水漚




。




能眀生滅理




。




劫劫永通流




。





想自浮生中




。




福田皆自利




。




如人
箭射空




。





力盡終還墜




。





俗願求真諦




。




如來教法深




。




微
音能洞達




。




憫起大慈心




。





諦性歸真理




。




寶山秘藏深




。




卷舒迷障路




。




達古便知音




。





語皆真實事




。




識量達觀音




。





從此忘言象




。




幽玄合本心




。





譬諸清淨人




。




經說心調御




。




世代常相親




。




別無有見處




。





言語重輕聽




。




因緣𢍆妙音




。




𡨋
觀諸聖境




。




幽默是非心




。





純熟知心了




。




真身丈六金




。




慈悲三界靜




。




惡趣海波深




。





和合諸煩惱




。




因緣喻海深




。




渡河三
獸喻




。




香象好相尋





。





喻言俱是空




。




有
相本無住




。




六念不曾離




。




真心迷道路




。





迷情魔未解




。




何法滌真心




。




同緣施一切




。




禪話問藂林




。





津濟本浮沉




。




眾生性不任




。




等閑無一事





。




白浪起
千尋




。





塵障眾生眼




。




空知福慧潛




。




不能問正法




。




波
底隱金蟾




。





圓融成萬法




。




道證菩提樹




。




及至果圓時




。




因緣自會遇




。





垢染無眀性




。




昬蒙世所嫌




。




忽然開悟後




。




初月細微占





。





往昔論三界




。




聖言一念思




。




精嚴通法
海




。




善
慧好施為




。





求去興何念




。




花開寶藏冝




。




性中成一
義




。




演法道心隨




。





滿心未足酬




。




秘密甚堅固




。





非道不能行




。




寂默真如路




。





人天垂報應




。




法界闡威儀




。




聖慧流如水





。




慈光普照時




。





種種莊嚴相




。




如來震法威





。




龍天
常護衛




。




安樂慧花飛




。





東受華胥國




。




人天行滿時





。




四
維及上下




。




朗鑒法無私




。





功力及圓就




。




悟來心不怖




。




若逢善影形




。




業種
歸何處




。





西極耶尼界




。




循環辯
法機




。




雖然增壽命




。




妙理化生遟




。





賢劫無為信




。




光揚日月輝




。




實言金口喻




。




妙覺正詮機




。





愚質四夷種




。




談空起是非




。




不隨根性識




。




散亂發
心機




。





德動堪消息




。




心平無嶮路




。




履之意
未調




。




苦不勞行步




。





三天金色界




。




像教世通時




。




化出琉璃殿




。




開張大法儀




。





信起波羅蜜




。




菩提接引時




。




經心施一法




。




樂道性中為





。





諦信何般是




。




中間勿妄為




。




未窮因果證




。




虛走坐忘
疲




。





利涉本無涯




。




清心離染污




。




如斯得自眀




。




欻若眀惺悟




。





語正真堪重




。




其如信復疑




。




義成無染著




。




自在法中
師




。





言惑多虛妄




。




經文大法儀




。




無心即是道





。




迷認少相知




。





御製秘藏詮卷第七



丙午歲高麗國大藏都監奉
𠡠雕造
