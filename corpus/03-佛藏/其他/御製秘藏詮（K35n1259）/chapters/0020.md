# 卷20

御製秘藏詮卷第二十　　　　　　駕





證始窮邊際




。




一眀萬盞燈




。




縱撗無障礙




。




展臂
法王興




。





志遂因心願




。




功成果自興




。




大乘無有
故




。




萬仞頂峯層




。





果認理虧少




。




雖多未足憑




。




行深無復見




。




水不離於冰




。





方便門中事




。




眾生業自重




。




𡨋心坐臥念




。




願力𨚗堪用




。





因不𢍆心法




。




元從道理興




。




真純無
動念




。




無减亦然增




。





義窮千刧相




。




清淨法王興




。




妙用信
心得




。




濁波萬𣲖澄




。





法說通眀覺




。




方依達者心




。




還知無
定相




。




寂與海齊深




。





旨露眀真的




。




乖為起妄心




。




未嘗興一念




。




善被
惡來侵




。





玄化同心識




。




宗邪徒伇心




。




迷情方寸內




。




經刧妄
追尋




。





幽暗人難測




。




方知道更深




。




不求能自解





。




君子重光陰




。





大丈夫能說




。




慈悲願力深




。




巍巍
圓智滿




。




妙道達知音




。





增減歸真諦




。




人󱍮經戒細




。




精
嚴坐道塲




。




地獄非兒戲




。





信解菩提種




。




經中說妙音




。




一言如洞徹




。




極意遠開襟




。





知見何曾障




。




真空理照心




。




玄中
含道識




。




鄙惡善投音




。





我本信如是




。




從來法海深




。




森羅
光大道




。




終不阻玄音




。





真風禪入定




。




塵翳六根侵




。




境界無諸障




。




幽奇自轉深




。





慧炬分眀照




。




圓光一切心




。




有情還
所著




。




爀熠善為林




。





說演經文教




。




真心化有情




。




色
身空受想




。




一法絕無聲




。





理勝他邪見




。




求緣不自聲




。




窮之
深妙性




。




消息更分眀




。





詮釋還源理




。




玄門不二成




。




窮
之不可得




。




達了境無聲




。





我說兩平等




。




善緣惡趣境




。




人心
勿妄語




。




拔舌閻王󲏰




。





求化因中實




。




非從有相聽




。




誰
人強分別




。




寂靜辯門󲊷




。





解遂非緣境




。




󳏧中漸得名




。




經関文引
論




。




迷悟覺他情




。





證智因中法




。




能持性上經




。




真如
心相遣




。




無漏自然醒




。





志淺求非遠




。




心行脚不行




。




矒然真
是境




。




達即悟無生




。





果諭愚癡軰




。




雪山道化
成




。




地因菩薩種




。




福業救眾生




。





因說來生果




。




無如一味情




。




華嚴經
廣大




。




諸聖𢍆真誠




。





義達經中要




。




金蓮萬葉生




。




深緣
容易得




。




甚處諭圓眀





。





法妄終無得




。




三途自不眀




。




門
󲊷真諦事




。




路要坦然平




。





無語勝相成




。




居高能作下




。




精
心觀自在




。




善相諸天化




。





說業因緣事




。




佛心化有情




。




凡迷
難自解




。




甚處達無生




。





玄了義中趣




。




五眀上聖行




。




不隨
雲水意




。




誰是到無情




。





幽隱無涯際




。




超昇善惡程




。




十方豋覺道





。




真理自然眀




。





大洽群生善




。




緣情事可精




。




無心
復不慮




。




賢聖道相成




。





信行無時捨




。




因中自不眀




。




坦然
依妙法




。




真界有名聲




。





智者祖師用




。




知空不暫停




。




運之無返覆




。




說法話堪聽




。





我見他方外




。




心緣鍊不精




。




身中空寂舍




。




利益有無情





。





真秘玄中有




。




非緣是不成




。




虛空非假合




。




真智本來眀




。





戒定貪嗔欲




。




昬衢居舍屋




。




因緣能諦信




。




不䧟
寒冰獄




。





慧引菩提證




。




施張道
眼眀




。




破
於非法相




。




區別善能精




。





說譬諭空色




。




三乘徧十方




。




捨迷求法易




。




似對釋中王




。





理順無為法




。




云何起信章




。




降魔成道業




。




功定入他
方




。





詮之不了悟




。




圓智豈名揚




。




妄執隨緣得




。




小升似
㪷量




。





求福先知妄




。




邪行道不彰




。




凝然歸性海




。




法要自開張





。





解即非難曉




。




因無二法張




。




縱撗知浩渺




。




福業事俱長




。





證念修行故




。




皆明󰡷益方




。




若依清淨
理




。





不壞是金剛




。





志樂還湏問




。




詮源事廣張




。




是非難自
曉




。





釋辯理歸長




。





果報依文釋




。




因明義㝡長




。




業隨身照影




。




善寂𢙣悠颺




。





因辯無邊性




。




其如要度量




。




法中眀隱
顯




。




廣大
起名揚




。





義滅眾生妄




。




凡愚智不長




。




方圓皆是習





。




萬
法一中王




。





御製秘藏詮卷第二十



丙牛歲高麗國大藏都監奉
𠡠雕造
