# 卷28

御製秘藏詮懷感一百韻詩卷第二十八𦘺





卜年興我運




。




化洽等無疆




。




肅穆
皆通濟




。




公平振紀綱




。




清朝遵禮讓





。




眀德遠馨
香




。




撫育同千古




。




恩臨溥萬方




。




從容安世俗




。




滌蕩順陰
陽




。




喜色浮丹闕




。




英聲徧八
荒




。




擇賢齊舜
禹




。




簡易習堯唐




。




得意乹坤
朗




。




慈和
雨露滂




。




彌隆輝麗日




。




正治
美甘棠




。




武藝皆奇絕




。




英聲雅不狂




。




和平關塞靜




。




健羨野民
康




。




瑞播卿雲匝




。




書觀乙夜忙





。




鳬趨金殿政





。





鼇抃玉𡎰傍




。




逈堡休
烽燧




。




邊兵戢虎狼





。




戎夷思德義





。




蠻貊奉梯航





。




治國三才順




。




雄文五色章




。




遐邇傳富庶




。




中外盡昭彰




。




墜典
冝常補




。




玄機理不忘




。




北燕窮
毳幕




。




南地足菰蔣




。




氣爽煙霞麗




。




鴻飛羽翼張




。




閑情空縹緲





。




逸志自汪洋




。




豐稔連遐土




。




謳謌
頌廣塲




。




遂心收逆壘




。




銜璧負牽羊




。




舉動
民皆樂




。




雍容物不傷




。




郊禋陳簠
簋




。




班序
儼珪璋




。





覆載從󳭪廓




。




周流任渺茫




。




歲時
朋聖曆




。




号令若嚴霜




。




蜀棧遊青嶺





。




荊湘貢白麞




。




高風躋五帝




。




盛德踵三
皇




。




秘閣摽圖史




。




掄材選棟梁




。




賑貧
施穀麥




。




貌儼見周姜




。




讓德歸
穹昊




。




精求用粃糠




。




殲刑羅狡猾





。





懸爵待忠良




。




風揭旌旗猛





。




雲橫醜虜
亡




。




生
靈皆有截




。





天道助時昌




。




布令施深信




。




憂民軫納隍




。





除祅揮寶刃




。




蕩
𰍈跨龍驤




。




宵旰
綏諸夏




。




勤劬服遠羌




。




狴牢冤
枉理




。




刑
政要威揚




。




從諫無留滯




。




溫恭柔勝剛




。




親耕
豐稼穡




。




有瑞集禎
祥




。




金闕來傳詔




。




銀蟾任意望




。




戶無扄夜室




。




海不起波浪




。





美譽功堪立




。




佳聲
孰敢當




。




輕風搖劒珮




。




巧舌似笙簧




。




德
重非身老




。




生踈欲面墻




。




上林多異菓





。




曲水引
廻塘




。




俊利韜機略




。




忠貞竭胏膓




。




松蘿
穿戶牖




。




筠色秀琳琅





。




玉帛堆盈
庫




。




軍儲
溢太倉




。





御製秘藏詮懷感一百韻詩卷第二十八



丙午歲高麗國大藏都監奉
𠡠雕造
