# 卷16

御製秘藏詮卷第十六　　　　　　駕





幽󷦾如是說




。




善道信心同




。




地獄非遙
遠




。




凡愚智不通




。





伏忍嗔心住




。




受持語自默




。




能
思一念時




。




眼覩天花出




。





不同彼有慾




。




聽受廣無窮




。




種福非
緣捨




。




心魔淨界中




。





信緣心不逆




。




安樂自然通




。




善法眾生得




。




如歸指掌中




。





智了何分別




。




周知幻化中




。




若能觀自在





。




如法滿虗空




。





蓬若夾蘭生




。




薰蕕悟染俗




。




非同
一氣類




。




寒暑相催促




。





我信眾生苦




。




來時去日同




。




善根
無惡趣




。




降伏妄心通




。





真諦更無說




。




迷情事更重




。




能
求知識見




。




境外自相逢




。





慧意重宣說




。




如來大信通




。




平心三界內




。




法體自優容





。





蒿萊同賤質




。




通理喻盈縮




。




若變世間心




。




願求真眼目




。





說經眀聽受




。




妄相盡為空




。




障礙無形影





。




詮源在處通




。





理勝皆無相




。




除疑任所從




。




經文論慧福




。




惡
草善因風




。





詮意心中妙




。




五真六化眀




。




金
剛堅固力




。





世法自蹤撗




。





昏法難眀照




。




𡨋心達妙覺




。




何曾有二三




。




理性盡通學





。





求梵藂林譯




。




高僧論亦通




。




凡情
知正覺




。




心印了然空




。





解譯中天語




。




因緣法相中




。




󳇐勒菩薩頌




。




如來一信
同




。





證果西方土




。




分眀善事同




。




一真
無委曲




。





高士解心通




。





善譯經文聖




。




法門喻的礭




。




若言諸世情




。




男子女人
惡




。





志願慈悲力




。




光含諒彼同




。




無
因無著相




。





消息自然通




。





果差難證覺




。




大戒一微中




。




寂淨
起諸界




。




因緣唯識通




。





因依無上果




。




聖道雪山峯




。




真實慈悲力





。




如來
一境空




。





香水灑壇塲




。




心通諸事實




。




欲知無上道





。




妄想忙終日




。





義從心識變




。




决利愛河中




。




始未知無益




。




清凉世界
空




。





法智修行妙




。




慈音徧九霄




。




唯心即是佛




。




禪定善根超




。





旨演真宗要




。




心逢意馬調




。




攀緣情猛
利




。




忍
辱自逍遙




。





風惡吹舡舫




。




縱撗不可測




。




迷心閑日月




。




秘教本來
密




。





玄網起大要




。




般若用周旋




。




法施皆精進




。




名揚
一義詮




。





幽僻含玄釋




。




隨情一切緣




。




湛然心不動





。




體性
量無邊




。





大信非常浬




。




超几入聖緣




。




根塵生怖畏




。




正法故親宣





。





悟空入自解




。




号曰維摩詰




。





方丈一張床




。




相知來問疾




。





信悟傳衣鉢




。




通流法相詮




。




因心持戒
故




。




妙理得如然




。





智攝眾生苦




。




悟依般若傳




。




佛言施
法信




。




利樂且隨緣




。





我問如來說




。




海中智寶詮




。




隨冝持淨戒




。




周智法相
宣




。





天降魔徒眾




。




神通不可匹




。




世尊一見時




。




懺悔無蹤跡




。





真見何為是




。




聖法極無邊




。




經通
無上義




。




色相澷虗傳




。





慧眼觀無極




。




眾生供養緣




。




聲香味觸法





。





布施廣周旋




。





說經十二部




。




一法智
周圓




。




功行三千界




。




無心是福田




。





精靈及四眾




。




妄
悟疑真實




。




意馬善調伏





。




經言
不可述




。





理證因多劫




。




貪生斷福緣




。




障同
魔境界




。




言
義不知詮




。





大義無通變




。




文乖自倒顛




。




非心求出離




。




法渡愛
河舡




。





求救眾生苦




。




無
心即是緣




。




但隨福與業





。




還離向人天




。





嚴潔非常淨




。




精修皆自得




。




目前施有益




。




證道暗中
出




。





解與行相違




。




難眀是與非




。




莫
矜誇巧拙




。




聖法許相依




。





證取波羅蜜




。




言名号羼
提




。




還
同甘露味




。




法要自東西




。





志遂千生劫




。




人天不阻違




。




存求無異見




。




報應
夢如歸




。





教本如來說




。




祛疑彼是實




。




執迷
皆妄想




。




煩惱悟心佛




。





果若隨心起




。




真
修五欲非




。




斷疑三障外




。




調伏法相依




。





有亦隨緣果




。




無緣覺不知




。




真
源若不動




。




取捨更何疑




。





義能依戒律




。




法上理無私




。




真諦
門中事




。




除貪妄想離




。





至德爍閻浮




。




四天轉佛日




。




解空六趣停




。




法相真皆實




。





御製秘藏詮卷第十六



丙午歲高麗國大藏都監奉
𠡠雕造
