# 卷17

御製秘藏詮卷第十七　　　　　　駕





法心不可得




。




供養禮󳇐陁




。




大震慈音遠




。




無遮了
義歌




。





旨傳千手眼




。




妙應薩婆訶




。





梵王同帝釋




。




修行曩劫多




。





玄門絕異見




。




降伏大邪魔




。




彼岸無為相




。




貪心溺愛河





。





幽深無遠近




。




禪定好相過




。




迷途如夢想





。




善緣
業力多




。





大士居兜率




。




千生積德多




。




慈悲無繫縛




。




善惡事消
魔




。





信心不可得




。




無執語云何




。




㸦起修行願




。




施恩智慧
訶




。





智見休名利




。




無心㝡福多




。




六塵
魔所使




。




豈得悟真麼




。





我見凡諸性




。




其如妄想多




。




眾生有佛種




。




悟不隔恒河





。





疑慮頓忘時




。




俄然達聖理




。




不看
波底妄




。




濁愛流清水




。





真本無虛妄




。




心邪即自魔




。





真成求始見




。




境界契摩訶




。





慧常無畏法




。




三事理難過




。




諸天咸信重




。




凡聖豈偏頗




。





說盡無遮聖




。




何如禮釋迦





。




纖塵皆是障




。




大利是僧伽




。





理事古今定




。




無勞發歎嗟




。




眾生如不悟




。




六
識盡迷虵




。





詮經不達義




。




覿靣見心邪




。




電轉心
中悟




。





芝蘭荊𣗥花




。





求善不求惡




。




無勞自見誇




。




眾生人定相





。




旱地種
蓮華




。





解種無邊福




。




因萌長善芽




。




智生皆不滅





。




佛眼看天華




。





志未成圓相




。




迢遙直道斜




。




若能眀取捨




。




定入
法王家




。





悟覺亦非難




。




心通遇法喜




。




遵依
曩劫同




。




凡聖歸真理




。





果報還須受




。




如何理不差




。




乖疑何即是




。




看取
井中蛙




。





因詰諸魔伏




。




真空定不邪





。





眾生能作悟




。




道路有相差




。





法祖初興日




。




祇園會上時




。




義
通無障礙




。




甚事更無疑




。





義顯難名狀




。




經文理不差




。




較量人
業力




。




佛
手亦難遮




。





旨實開方便




。




如來真大師




。




攝心三昧
裏




。




悟解性相知




。





玄中知大聖




。




般若智心持




。




斷
障無眀息




。




三乘理理虧




。





幽顯諸天證




。




誰人得暫時




。




非心行利樂




。





作念勿參差




。





詔譯五天梵




。




經文布徧時




。




眾生承利益




。




三界大師慈




。





知法闇中眀




。




常行方便理




。




無窮煩惱障




。




魔善冤家鬼




。





信極恒沙劫




。




然燈繼續時




。




人
天無福望




。




即此是菩提




。





智繞檀郍境




。




因眀起大悲




。




心邪空
妄想




。





聖道信何疑




。





我聞增減力




。




唯佛大慈
悲




。




論釋皆如是





。




修行人
不知




。





真金妙色相




。




信重法王師




。





理性本無礙




。




非人強
說之




。





慧黠人堪比




。




非言勿強知




。




真誠無相種




。




證見天
人師




。





說境皆微妙




。




一宗
萬法持




。




迷途真隱顯




。




善惡不
相離




。





理妙迷中出




。




達人定不疑




。




縱橫知利益




。




聞
善但多為




。





詮文何所措




。




誰是復誰非




。




隱顯分眀
法




。




心通入有󳏧




。





非心非是法




。




法與心相似




。




悟即
諸緣合




。




無求達妙理




。





求二歸一法




。




此道甚玄微




。




實相當來意




。





心從般若依




。





解脫離煩惱




。




真心不可非




。




攝持如是法




。




利樂有玄
機




。





證真無礙理




。




出沒道心機




。




何
物行深理




。




修持沒是非




。





志遠情非近




。




發心兩自知




。




其中顛倒故





。




因地欲何
為




。





思願不思議




。




未嘗一理虧




。




於緣無礙故




。




當逢不滅時




。





因果何須問




。




從真即我師




。




法心無所戀





。




顛倒
勿生疑




。





義歸真諦信




。




一理貫無知




。




泡幻皆諸妄





。




賢愚
即是誰




。





法号因中佛




。




功果不思議




。




四十九年事




。




彼論亦無疑




。





攝受真心種




。




善緣皆入耳





。




人賢清淨樂




。




十地因中起




。





旨諭真如教




。




非途道可思




。




凡情不可得




。




般若
到無知




。





玄中不可度




。




得路達幽微




。




當說無知
見




。




如何免是非




。





幽隱難分別




。




言論郍是非




。




聖人知見孰




。




所以達
幽微




。





豈論人巧拙




。




智昧亦何疑




。




有相迷諸念




。




多聞少不知




。





信滿人天界




。




六塵垢不知




。




果因菩
薩證




。




乞取聖
凡時




。





御製秘藏詮卷第十七



丙午歲高麗國大藏都監奉
𠡠雕造
