# 卷21

御製秘藏詮卷第二十一　　　　　肥





御製佛賦




妙覺玄門




。




佛聖知原




。




取
捨金輪之位




。




利樂
給孤之園




。




六法󳇐深




。




靈境而故非眇小




。




三界圓滿




。




清淨而曩
劫常存




。




念想
當初




。




周旋梵會




。





降吐九龍




。




因從十地




。




有情而無不
攝受




。




種相非儀





。




迷途
而頓悟修行




。




緣同解意




。




由是
遠離迷津




。




觸類皆空




。




眾生寂滅於顛倒




。




菩薩得躡於真蹤




。




修道雪山




。




枯槁之形體皆瘦




。




施張法教




。




摩訶之性智潛通




。




喜動灌
頂之徒




。




天花如雨





。




位顯無垠之上




。




恒作方便之主




。




菩
提道廣




。




聽金口以宣言




。




自在逍遙




。




化銀闕而斯覩





。




云何
一切




。




寂靜三無




。




莫辯精心之舍




。




慧分破暗之厨




。




迷途而邪執尚昬




。




貪癡皆障




。




達識而
終歸曉了




。




智慧堪居




。




思一念兮興異




。




想千世以何殊




。




故其慷慨怡然化諸有漏





。




寒熱之生老病苦




。




月宮之蟾光白晝




。




視慈雲之
忽至




。




󳇐逐妙音




。




鄙妄想之縱撗




。




良緣自
透




。




且夫福業相隨




。




哀憫之悲




。




曠刧而無遮
信受




。




莊嚴
而去就皆冝




。




揚法而芝蘭並秀




。




宗經而道性堪為




。




軒盖化成




。




將辯根塵之相




。




慈悲宴
坐




。




喻
超戒定之基




。




於戲大教開
張是非鄙俚




。




與天地而同久




。




散馨香而綺靡




。




心猿意馬




。




惑境界以何
多




。




火宅冤家




。




勿慵墮於彼此
已矣哉




。




天上人間無不
歸於真理




。






御製佛賦




聖種者積善功而化之




。




離六情
而得清淨




。





尊三界以作大師




。




降伏一切之魔
心皆歸正法




。




智通千識之妄想攝受慈悲




。




佛下生於兜率天宮殊
勝緣故




。




降時而九龍吐水




。




應現而一法如雨




。




周宣教受仙花而碧落芬
芳




。




馥郁軿羅
寶殿而煙霞舉措




。




盖為貪瞋濁世道演將敷




。




恩施
物外信及有無




。




雙林之樹下隨
喜一念而譬喻昬衢




。




知非捨戀求真實堪
依仗




。




得逢利樂
緣寂自在鋪舒




。




豈不知大海無涯




。





諸天事廣




。




猒宮中粉黛之
色




。




棄尊貴輪王之上




。




蓮花生處舉意而動合周旋




。




衣鉢隨時悉是真純之相




。




莫不魔緣恐怖鐵皷威聲





。




覺閻浮之愛境
達幽闇之無眀




。




三乘
之性相皆空觀音自在




。





十地之因緣解脫啟諸有情




。




應現四十
九年




。





歸空告滅




。




演涅槃般若之智





。




寂阿
祇淨度之劫




。




時也深窮
幻夢法體如來




。




宣秘旨於山中




。




授然燈之佛說




。




故知忍辱
為妙大覺聲聞




。




芥子納須󳇐之國




。




蓮華生足下之雲




。




舒
卷之煩惱皆除其何語默




。




讚歎
之含生布慧照破迷群




。




巳而變化神通普霑性德




。




悲末
刧之有限貫靈臺而不易




。




娑婆之世界圓滿




。




菩提
之道果重滌




。




我今志慕於
真如一心歸依於向佛




。






御製詮源歌



詮源歌。



。




昔有佛者




。




於五百世前
持忍辱緣




。




妙
覺如來本大仙




。




苦行慧超昬衢暗




。




三昧因中
人不見




。





救度眾生蘊慈悲




。





無量劫來多發願




。




方便門開智慧觀




。




萬法從頭皆一貫




。




道
行清高何障礙




。




五濁惡世堪修鍊




。




堪修鍊




。




歸至理




。




無邊國土恒沙水




。




圓滿化身知不
知




。




七寶湏󳇐納芥子




。




芥子細




。




人行󱍮




。




雪山
清淨是真如




。




真
如果證信心重




。




降下山河皆
搖動




。





舉步蓮花崛山中




。





帝釋梵王相𨒦送




。




般若智




。





破煩惱




。




根性自然菩提道




。




清淨色空
座逍遙




。





󳇐勒緣寂無顛倒




。




比丘僧




。




比丘尼




。




來聽法




。




唯願
慈悲分解說




。




故非眇小是修
行




。




經戒相違有罪業




。





善男子




。




善女人




。




愛河不
渡䧟迷津




。




波羅蜜相真
堪信




。




遠離
六情果從因




。




果從
因




。




豈願足




。




深淺隨機皆是欲




。




達磨之心終不曲




。




品度俱為
䪺漸久




。




戶牖
開張相擊觸




。




大
攪長河為酥酪




。




覺悟賢眀迷自縛




。




舉
體全歸三界空




。




病
藥施投㸦更作




。




振綱領
而無強弱




。




邪妄若來皆銷爍




。




一切隨
緣有是非




。




世尊利益心安樂





。





御製秘藏詮卷第二十一



丁未歲高麗國大藏都監奉
𠡠雕造
