# 卷15

御製秘藏詮卷第十五　　　　　　駕





信及生緣業




。




生緣情莫齊




。




攝心歸佛理





。




達處絕狂迷




。





智識非深淺




。




真心用可
躋




。




有情無處用




。




理性有高仾




。





我見眾生性




。




如何却自迷




。




愚癡開不悟




。




豈諭隔雲泥




。





西域論金人




。




東流遷大道




。




萬里取經廻




。




普慧慈悲照




。





真實無虗法




。




如
來等一齊




。




更無分別相




。




即此是菩提




。





慧通三昧性




。




三乘一法齊




。




迷情
終未悟




。




解了不心迷




。





論空方便理




。




上智不求來




。




頓悟達真
際




。




𡨋然
水月開




。





賢聖化無明




。




情田耨
忍道




。




佛法因地力




。




七種湏󳇐寶





。





理諭懸河辯




。




身觀自在來




。




一宗超
百億




。




妄想豈能裁




。





詮法本無見




。




微音去自來




。




玄機唯寂
默




。




倐
忽到靈臺




。





求法將何用




。




虛無有自來




。




眾生緣業
重




。




不悟可哀哉




。





愚惡貪嗔恚




。




迷情違大道




。




若逢
如意珠




。




福德莊嚴造




。





解講千經論




。




能亡人我乖




。




聖
理如不悟




。




法要豈梯階




。





證了因來果




。




真常有洞開




。




不能明一
法




。




滿目翳塵埃




。





志啔如來藏




。




非論萬億垓




。




靈山宣妙
偈




。




諸
境欻然開




。





舒展他方界




。




菩提妙相好





。




心
開一切智




。




熏習去煩惱




。





果熟祇園說




。




輪廻理道開




。




信知
熏習力




。




方便認當來




。





因假緣為事




。




緣隨因
自來




。





有緣相𢍆合




。




寂靜萬靈開




。





義且非人意




。




心非性莫來




。




眼看無一物




。




六賊混塵埃




。





滅盡人天惡




。




慈光懷聖抱




。




法身在眼前




。





障礙無心討




。





法道歸真智




。




終超
出世情




。




猶如華藏海




。




不縮又無盈




。





旨論通玄說




。




強名不是名




。




綿綿而
不絕




。




境像自分眀




。





玄識廣諸教




。




真詮意
渾成




。




滿空如白雪




。




響谷應來聲




。





疑信似迷猿




。




人心多返覆




。




但依
真實理




。




絃直豈曾曲




。





妙理莊嚴相




。




通經自
適情




。




真源常湛淨




。




出沒自縱撗




。





大智非求得




。




恒沙諭物情




。




無邊皆是教




。




覆餗不通明




。





信解受持者




。





經文不自聲




。




金剛般若智




。




論釋六緣情




。





悟則背時流




。




迷來昧器局





。




修行若直心




。




圓滿無斜曲




。





智者求無二




。




經題一等平




。




眾生
疑自苦




。




正解得𠇲聲




。





我恐眾生見




。




根緣被愛情




。




提撕明
注意




。




瞹昧信難成




。





真語真如語




。




八風
散杳󷦾




。




澹然銷妄識




。




萬法藏中
經




。





知過能而改




。




清心無自辱




。




如能隨
日用




。





春煦變寒谷




。





慧日破諸闇




。




如空豁大明




。




六塵
隨壞刧




。




我佛正無情




。





說法無邊際




。




誰人解發明




。




如來常寂嘿




。




煩惱辯諸情




。





理顯心無妄




。




太陽景自明




。




利緣
彰本末




。




福業應來情




。





非是他緣業




。




烏飛月兔速




。




朝昬無處用




。




色相何拘束




。





詮理求幽細




。




教行義要精




。




向知
非少剩




。




眼內勿求聲




。





求得非言意




。




其中物外情




。




筌
蹄因果悟




。




方現一珠眀




。





解釋詮源理




。




三天徧八紘




。




斷疑心
妄著




。




起信願非輕




。





江海桑田變




。




愚癡
躭嗜慾




。




若能心自了




。




真實無偏曲





。





證義云何有




。




周旋論道成




。




敲冰求覓火




。




何日達
無生




。





志心思見佛




。




佛不阻眾生




。




自是心無徹




。




何時道業成




。





果性因緣種




。




持齋及誦經




。




自家無道理




。




心地豈惺惺




。





海量潮宗水




。




澄波萬文淥




。




法舡如得渡




。




三界諸天速




。





因如常假合




。




一念一分眀




。




法以云何是




。




視現
兩無成




。





義有修行喻




。




豈教虗妄生




。




還如第一義




。




三際坦然平




。





法應無所住




。




南北及西
東




。




唯有一宗法




。




空知大道雄





。





降彼袪人我




。




斯言非委曲




。




捨邪歸善道




。




照破無明慾




。





旨諭顛來倒




。




菩提道果同




。




能心
除二障




。




善達惡緣風




。





玄誦經文說




。




色身相一宗




。




發心能戒忍




。




精進利煩籠




。





御製秘藏詮卷第十五



丁未歲高麗國大藏都監奉
𠡠雕造
