# 卷12

御製秘藏詮卷第十二　　　　　　駕





解即無邊智




。




清流不見冰




。




因言而立意




。




佛戒剃頭僧




。





愚迷能解悟




。




報應可登陟




。




行有
善因蹤




。




往來皆得力




。





證不眀於果




。




果因復不興




。




欲求清淨理




。





方丈問高僧




。





志遂還他暗




。




三衣粥飰僧




。




坐禪勤論道




。





免墮業緣燈




。





果證來多刧




。




還緣有愛憎




。




無憎兼不
愛




。




非橫
豈相凌




。





舒慘豈關情




。




悲㦲空歎息




。




貪心不解脫




。




法用無
窮極




。





因刧何曾減




。




非因刧不昇




。




但
隨因刧理




。




真實事為憑




。





義舉千千億




。




眾生勿妄興




。




勸知休作
用




。




大海
百川稱




。





法求無二說




。




意默自然通




。




心不著
空相




。




菩提道果同




。





卷舒不繫念




。




何是孰難測




。




達則𠛴
那間




。




眾生多幻惑




。





旨真袪妄想




。




達了盡成空




。




種𪫬皆為定




。




愛河渡
筏中




。





玄入虛无境




。




善緣有業風




。




不惟高與下




。




佛理智
圓通




。





幽寂乍濛濛




。




圓眀了自通





。





更無施巧拙




。




坦蕩化玄穹




。





疑慮深無底




。




空心印二月




。




昬蒙幽顯理




。




虛妄何分別




。





大戒如來子




。




修行
萬法中




。




智求
心上得




。




三界大師雄




。





信不窮深奧




。




山河與地同




。




不唯阿頼識





。




隱顯杳󳸓中




。





智欲周沙界




。




慈光導世
風




。




遐荒無不被




。




威德顯穹崇




。





悟在𠛴那間




。




迷中何濟拔




。




望陽入有無





。




覺後無
狂渴




。





我將譬喻說




。




窮劫淺深通




。




唯有
真空理




。




圓眀六合中




。





真空不可見




。




萬劫杳󳸓中





。




日日
知盈縮




。




冝然幻化同




。





慧甚何分別




。




阿那陁識中




。




深藏諸種
子




。




瀑水各西東




。





知本還其末




。




真心方了達




。




兼能行布施




。




山上望
明月




。





欲說是非同




。




如常理亦通




。




六根湛清淨




。




五陰本來
空




。





理近凡心遠




。




道存理不通




。




深窮真諦事




。




寂靜信無窮




。





詮言要的實




。




立意喻言通




。




若解非情見





。




真
緣義理融




。





非本色皆空




。




幽󳏧眀始末




。




體真無妄動




。




塵垢身清
潔




。





覺聖無為法




。




修心一念中




。




但求無事去




。




習性徧虛空





。





行與解何同




。




由來一義中




。




若無分別相




。




真實自含容




。





證善何人解




。




終成一義空




。




輪廻
無了日




。




惡業善心同




。





江河與大地




。




智慧無纖默




。




根本是煩惱




。




寂然中
一物




。





志蓄人儀表




。




縱橫不可衝




。




更能歸
正見




。




萬刧自從容




。





果敢亦奇士




。




不唯賢與庸




。




若然知道
覺




。




業力自銷鎔




。





因機興妙用




。




勝事會遭逢




。




世福有深厚




。




當來善必從




。





海納百川水




。




一非終是一




。




眾知等妙
覺




。




惣攝戒兼律




。





義可貫眀日




。




巍峩善事雄




。




更眀真實理




。




萬象隱其中




。





法滿真空界




。




如來大覺中




。




眾生
是佛智




。




密教豈通風




。





旨玄行大信




。




信立示愚蒙




。




不會信中
信




。




聞音
耳却聾




。





降魔大眾力




。




萬法從心入




。




生滅化無
情




。




少
求多亦得




。





玄默非相應




。




寂然天地中




。




凡思兼與
聖




。




微妙
悉皆通




。





幽深行至道




。




小異大家同




。




無礙兼心智




。




凝
然湛寂中




。





大哉深信士




。




一語便音風




。




纖芥心中得




。




善隨惡
業空




。





伏性若寒灰




。




任從枯栲質




。




若能養聖胎




。




去二還歸一




。





信及四天下




。




寂然一貫中




。




誰能覿
妄想




。




真性隱虛空




。





智慧有增減




。




心貪惣是空




。




未知施設用




。




權變類真風




。





我知山聳翠




。




劫壞地平同




。




實理無高下




。




歸空運化中




。





蓬長類麻生




。




薰蕕相㒵直




。




溟濛法雨
滋




。




可漸
性中得




。





真不與妄合




。




恒沙妙相同




。




諸大與聖眾




。




達識
大乘空




。





慧本因緣得




。




十方所在通




。




欲眀真諦理




。




人法
兩相宗




。





說經兼說論




。




經論信心同




。




不說及常說




。




因
緣幻化空




。





蒿產於凡草




。




榮枯無了日




。




勿生分
別心




。




各自
本緣出




。





御製秘藏詮卷第十二



丙午歲高麗國大藏都監奉
𠡠雕造
