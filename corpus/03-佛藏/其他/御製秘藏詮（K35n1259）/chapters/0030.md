# 卷30

御製秘藏詮懷感廻文五七言詩卷第三十





五言　　　　　　　　　　𦘺




眀哲賢高士




。





遠深甚更長




。




清風搖影轉




。





滿月瑩寒光




。




英𮥸皆才用




。




品流見異常




。




生平觀
至道




。




化俗
蘊馨香




。




榮貴空知命




。




去非免作荒




。




輕
波雨水混




。




裊柳樹枝狂




。




迎也春將盛




。




送歸秋亦忙




。




精神何氣
骨




。




政理頌甘棠




。




行孝
慈仁德




。




樂為惠有方




。




盈盈對賞詠




。




興罷若存亡




。





亡存若罷興




。




詠賞對盈盈




。




方有惠為樂




。




德仁慈孝行




。




棠甘頌
理政骨氣何神精




。




忙亦秋歸
送盛將春也迎




。




狂枝樹枊裊
混水雨波輕




。




荒作免
非去




。




命知空貴榮




。




香馨蘊俗化




。




道至
觀平生




。




常異見流品





。




用才皆𮥸英




。




光寒瑩月滿轉影搖風清




。




長更甚深遠士
高賢哲眀




。






七言




情非亦好皆齊一




。




去住懽心事對
酬




。




誠信樂教花盡發




。




得中高接霧輕收




。




爭開競秀和香色




。




儼雅相逢靜
㝡幽




。




眀日麗來朱紫殿





。




細雲搖曳瑩朱樓




。




名揚可大終奇異




。




禮讓
能謙遂勝遊




。




呈
瑞眾多唯景福




。




應祥冝自集禎休




。




聲聞遠令遵依政




。




士
庶咸知斆聿修




。




橫有竪機深
理道




。




進賢忠莭溥分憂




。




清天照鑑還寧泰





。





白雪歌詞𮥸易搜




。




兵偃順戈閑
戰馬




。




意全通佇思悠悠




。





悠悠思佇通全意




。




馬戰閑戈順偃兵




。




搜易𮥸詞歌雪白




。




泰寧還鑑照天清




。




憂分溥莭忠賢進




。





道理深機竪有橫




。




修聿斆知咸庶士




。




政依遵令遠聞聲




。




休禎集自冝祥應福景唯多眾瑞
呈




。




遊勝遂謙
能讓禮異奇終大可揚名




。




樓朱瑩曳
搖雲細殿紫光來麗日眀




。




幽㝡靜逢相雅儼




。




色香和
秀競開爭




。




收輕
霧接高中得發盡花教樂信誠




。




酬對事心懽住
去一齊皆好亦非情




。





御製秘藏詮懷感廻文五七言詩卷第三十
