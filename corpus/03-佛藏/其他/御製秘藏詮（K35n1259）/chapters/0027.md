# 卷27

御製秘藏詮懷感一百韻詩卷第二十七𦘺





仰望長空非霧散




。




臨危俯視景星孤




。




猛風似箭吹砂磧




。




遇雪巡樓釅酒沽




。




膳部少曾加饌味




。




太常雅調雜笙竽




。




將癡
欲為虛求劒




。




性僻還應但守株




。




媚侫乖張多自惑




。




公行譚論不咨諏




。




指蹤怠𢢔真堪
辱




。




勤儉清廉濯舊襦




。




受寵若驚皆得所




。




揚名顯行豈違踰





。





舞風垂柳輕藍色




。




笑日名花似錦鋪





。




巷聽
歌時相倣斆




。




仁慈布慧盡昭蘇




。




夏田𡑅
壠同康濟




。




秋稼如雲不欠租




。




我武惟揚宣致理




。




崇文
柔遠播中孚




。




廣
開視事洪纖達




。




庶務從容自遣祛




。




戈甲豈施杭越定




。




梟巢已下𣈆陽屠





。




彤󲊷濟濟依班敘




。




輔弼鏘鏘𣫆保樞




。




帶礪勳侯推
果毅




。




貔貅羣効
悉何如




。




頒霑煥赫皆傾節





。




錫宴冲融許大酺




。




西洛荒榛經嵗久




。




東京繁盛往年無




。




爕調宛順璿璣正




。




郊祀虔誠
禮樂徐




。




紫殿成名增𮥸
彥




。




金門脫灑免嗟吁




。




瓊漿美醞供盈甕





。




嘉會眀堂設內𢊍




。




憫惻降
祥呈効祉




。




恤刑高鑒眚嚴誅




。




奔聽肆
赦臻靈貺




。




盡放從良改賤俘




。




漸變澆風歸質朴




。




普施寬濟
並沾濡




。




蒸黎滿望湏虔禱




。




苗稼無災絕舞
𩁹




。




引領情通深可
重




。




舒張妙理謾欷歔




。




禹功及物玄珪受




。




湯󱶈推仁尚泣𦍬




。




𰍈盜屏除潛惡跡




。




兇頑悛
革悟榮枯




。




旁求𮥸造為心膂




。




周想
昔賢猶病諸




。




所在怡然頒弊帛




。




搜羅幽滯遍門閭




。




耿光褒稱竆編
簡




。




紀錄湮沉
被野廬




。




省分推誠堪作則




。




因循委命
笑揶揄




。




垂𠇲烈世遵先古





。





側陋遐宣共坦途




。




納諫為緣無忌諱




。




滋章却恐
信欺誣




。




酬恩環在知黃雀




。




表瑞年祥見
赤烏




。




靜聽中
原歸歷𰚆




。




晏安域內放懸逋




。




彛倫庶績熙哉盛




。




眾恱難儔務本與




。




丹󲈺
鳳儀翔紫閣




。




六眸龜出泛清渠




。





興隆大寶宗皇業




。




亭育羣生盡樂
𦙃




。




枉恣昏迷誇調
態




。




踈
狂醉臥豈堪扶




。




隟中平地香多潔





。




廉讓之家水不污




。




得意勿輕成
浪跡




。




情憐光景隱巖峿




。




瓊林㝡好齊三境





。




畫舸應
難渡泗洙




。




獫狁
來賔閑甲馬




。





關防無事罷戈𪠲




。




煩苛已變眀真偽




。




威德遐臨懾虜胡




。




造化󳭪崇
資勝境




。




施張利益振嘉謀




。




生民務本傾
葵藿




。




耕
叟懽欣滿路衢




。




通義尋常皆𰦧礪




。




開襟寂
靜若醍醐




。




但看佳氣籠金闕




。




何異神仙化玉
壺




。




審逐稽違聲自遠




。




廉平慎守道
情俱




。




熙熙大
布無為化




。





咸使飛沉向帝都




。





御製秘藏詮懷感一百韻詩卷第二十七



丁未歲高麗國大藏都監奉
𠡠雕造
