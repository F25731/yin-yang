# 卷2

御製佛賦



聖種者積善功而化之。



。



離六情
而得清淨。



。




尊三界以作大師。



。



降伏一切之魔
心皆歸正法。



。



智通千識之妄想攝受慈悲。



。



佛下生於兜率天宮殊
勝緣故。



。



降時而九龍吐水。



。



應現而一法如雨。



。



周宣教受仙花而碧落芬
芳。



。



馥郁軿羅
寶殿而煙霞舉措。



。



盖為貪瞋濁世道演將敷。



。



恩施
物外信及有無。



。



雙林之樹下隨
喜一念而譬喻昬衢。



。



知非捨戀求真實堪
依仗。



。



得逢利樂
緣寂自在鋪舒。



。



豈不知大海無涯。



。




諸天事廣。



。



猒宮中粉黛之
色。



。



棄尊貴輪王之上。



。



蓮花生處舉意而動合周旋。



。



衣鉢隨時悉是真純之相。



。



莫不魔緣恐怖鐵皷威聲。




。



覺閻浮之愛境
達幽闇之無眀。



。



三乘
之性相皆空觀音自在。



。




十地之因緣解脫啟諸有情。



。



應現四十
九年。



。




歸空告滅。



。



演涅槃般若之智。




。



寂阿
祇淨度之刧。



。



時也深窮
幻夢法體如來。



。



宣秘旨於山中。



。



授然燈之佛說。



。



故知忍辱
為妙大覺聲聞。



。



芥子納須󳇐之國。



。



蓮華生足下之雲。



。



舒
卷之煩惱皆除其何語默。



。



讚歎
之含生布慧照破迷群。



。



已而變化神通普霑性德。



。



悲末
刧之有限貫靈臺而不易。



。



娑婆之世界圓滿。



。



菩提
之道果重滌。



。



我今志慕於
真如一心歸依於向佛。



。
