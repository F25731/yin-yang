# 卷3

御製逍遙詠卷第三　輕





逍遙心自樂




。




清淨
保長生




。




至道
歸玄理




。




真空造化
成




。




輝華揚日彩




。




偃仰順風聲




。




裏外有何物




。




剛柔鍊始精




。





遁跡深巖谷




。




身閑未是閑




。




研窮堪語默




。




寂靜杳󳸓間





。




秘密
逢邪見




。




難開大
道関




。




金丹無
効用




。




弗可返童
顏




。





金鼎精湏鍊




。




華池水火紅




。




坎离能匹配




。




男女自
相逢




。




曩刧知
因果




。




生前道不窮




。




若修方寸是




。




發意便周通




。





修鍊求真一




。




冲和本自然




。




希夷光滿月




。




響應
直如絃




。




苦學周知易




。




難窮語默玄




。




成功兼積德





。




別有洞中天




。





一法從何有




。





二皇五帝前




。




周知多異境




。




猛利
要精專




。




我命湏
依道




。




陰
功及物緣




。





善心通感應




。




動靜理深玄




。





日照光文彩




。




周通
無不関




。




天思功㝡
大




。




地載莫𠇲
閑




。




絕頂孤
松老




。




飛雲野鶴
還




。




玄珠名隱
奧




。




杳靄路𭭛
間




。





清靜常清靜




。




緣來盡可行




。




道高麋鹿性




。





庸識歲年輕




。




日吳相依勢




。




花開觸處明




。




是非論巧拙




。




達外福蒼生




。





真境堪依仗




。




周
遷四敘移




。




人忙閑聖跡




。





心達罷狐疑




。




俊造
皆流品




。




逢能
即是師




。





二從寒暑變




。




龍浴鳳皇池




。





戶牖常開閇




。





升沉倐忽中




。




龍吟深邃理




。




虎嘯語言通




。




南北思長遠




。




東西道不窮




。




炎光𠬧月魄




。




桂樹發花
紅




。





鼎內蓮花出




。





如塵發絳紅




。




坎鈆
將匹配




。




离火好相
逢




。




陰散何優劣




。




陽歸自合同




。




消停方可信




。




輝華大道雄




。





青龍本屬木




。




白虎作華池




。




水火恒為則




。




陰陽造化
遅




。




清心常積德




。




凢眼豈能知




。




君子𦗟吾喻




。




神明勿闇欺




。





萬靈通有感




。




臧否在名人




。




志誠昭
明德




。





清淨見於真




。




奉道惟恭謹




。




修持
願本因




。




廣將求利益




。




苦樂救生民




。





頂戴尊天地




。




𦖟明識
見高




。




無為通理性




。




猛利豈虛勞




。




出沒終難認




。




因緣不可逃




。




中原多聖境




。




四海湧
滔滔




。




世界諸方聖




。





如同在眼前




。




其於通要妙




。




便見理深玄




。




法教窮難盡




。




周知本自然




。




信誠含萬象




。




秘隱口親宣




。





隨緣心不見




。




性各
本來真




。





𢙣事誇脣頰




。





愚癡似醉人




。




忙忙何物有




。




急急利名親




。





入定觀浮世




。




蒼生業感因




。





善念銷嗔恚




。




無
差本自然




。




花開
凢葉木




。




水打急風舡




。




拘執恒如縛




。





能仁斆昔賢




。




神
明皆正定




。




消息
更深玄




。





逍遙賢聖樂




。




我悶俗情愚




。




鄙俚何堪𰚆




。




斟量
解卷舒




。




𢙣緣湏盡去




。




善事好相於




。




忙急真如夢




。




𠃵坤造化殊




。





宿願通賢聖




。




貪心
勿強為




。




眼前
銷𢙣趣




。




天鑒故無
私




。




如夢何光景




。




明神所在知




。




精修觀出離




。




解脫影相隨




。





不爭多氣力




。




容易可成功




。





意馬湏調伏




。




如塵幻
夢中




。




任持從
雅淡




。




樂道定雌
雄




。




修鍊
知勤苦




。




因緣自合
同




。





一受諸同氣




。




凞和理道平




。




乘雲無滯礙




。




大樹
種而生




。




塵垢勿教染




。




江河順不爭




。





機智潛弃用




。




方顯貴佳名




。





御製逍遙詠卷第三
