# 卷2

御製逍遙詠卷第二　輕





人救眼前󵘌




。




何
曾利益心




。




愚
迷終淺見




。




達
者智高深




。




苦行
湏知應




。




餘憂力不任




。




經書無限
意




。




稽古便
同今




。





逍遙安且定




。




但信
莫懷疑




。




大海
波中水




。




狂風
樹擺枝




。




樂天
分造化




。




慧眼
細觀之




。




方
寸無諸惡




。





恒將利益持




。





恍惚人難曉




。




天仙
語默玄




。




修心
無道理




。




終日自忙
然




。




我命真中
趣




。




長生認宿緣




。




機權饒使用




。




聖事不虛傳




。





清虛閑靜得




。




奉道見真歸




。




契合皆
堪用




。





因緣事好依




。





精誠求諦信




。




湏有是兼非




。




豁達幽深遠




。




奧妙入玄機




。





清靜人安樂




。




恒持要久長





。





秋天澄皓色




。




春
日發輝光




。




一氣
從初立




。




三才位不忙




。





群生如似夢




。




甚處得馨香




。





道者強名立




。




清虛隱顯深





。




欲行千里路




。




別探一般心




。




景象
空天遠




。




何勞意馬尋




。




玄談通智慧




。




曩刧
至從今




。





𡨋搜多景趣




。





悟則䪺神清




。




拘束終難得




。




冲
和入道情




。




知微
通理性




。




滋
味好研精




。




妙用天
然法




。




陰功
蘊大名




。





氣類湏相假




。




陰陽
造化成




。




離凢
知有聖




。




得外
更求精




。




先秘
庚辛理




。




後傳戊
己名




。




真
鈆歸一體




。




交感自
長生




。





天界殊勝理




。




凡愚不易知




。




曩因誰可究




。




淺近故懷疑




。




的實歸真性





。




區邪入正
持




。





樂耶親大道




。




報應自然之




。





知之修鍊法




。




便
是聖中人




。




有象虛無境




。




邪緣不見真




。




恒持功行益




。




響應甚平均




。




渾然天地理




。




大道徧𠃵坤




。





伏藏終不見




。




巧拙是兼非




。




至道光懷古




。




周通隱聖機




。




清天何物
性




。




濁地故相依




。




修鍊真堪惜




。





踈慵有順違




。





夢𥧌其中物




。




常人
何得知




。




陰寒三𰚆
變




。




陽暖兩相冝




。




宿
世終皆有




。




無
緣勿強為




。




真鈆歸
至道




。




龍虎笑華
池




。





形影隨人得




。




精修道不迷





。





研窮深理路




。




造化隱端倪




。




雲引龍吟󲈺





。




風生虎嘯溪





。




少知愚豈解




。




南北與東西




。





鷰雀不生鳳




。




陰陽一氣全




。




無窮深可及




。




境象理推
遷




。




奚益
其形化




。




平章語默玄




。




終
身何所伇




。




道本豈私焉




。





自在無拘束




。




逍遙裏外安




。




頑情終不見




。




聖境類乎端




。




機智將
何用




。




幽深大道寬




。




區分能解意





。




四季一
周看




。





求得真宗一




。




深知萬象清




。




自然通感應




。




意外別長生




。




斆
古身何措




。




輝華日瑩眀




。




誰窮天地理




。




去住兩無成




。





不醉迷如醉




。




猶貪巨鼎扛




。




通玄求得一





。




清靜更無
雙




。




鸞鳳拪
瑤渚




。




天津𡑅漢江




。




欲窮何所似




。




夜月透雲䆫




。





利鈍猶根性




。




無緣枉用心




。




邪求皆是相




。




正定理玄深




。




巧拙高含識




。




輕浮
力不任




。




大乘通
語默




。




稽古便知今




。





笑盡人間事




。





到頭惣不知




。




信心終是實




。




如日瑩無欺




。




舉措持恒久




。




貪生却似癡




。




善緣銷惡趣




。





惠愛廣將施




。





五金并八石




。




一一
注仙經




。




雅
有深仁行




。




無
非不暫停




。




日華
精汞法




。




月魄鍊
砂靈




。




入聖超凡骨





。




變化本真形





。





御製逍遙詠卷苐二



甲辰歲高麗國分司大藏都監奉
𠡠彫造
