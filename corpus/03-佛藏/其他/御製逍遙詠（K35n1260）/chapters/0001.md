# 卷1

御製逍遙詠序　　　　　輕



玄元大道理包深遠。



。



逍遙
至論義貫精微。



。



朕聽覽之餘留心
緗帙。



。



三墳五典
頗識指歸。



。



金匱玉凾亦
探玄奧。



。



嘗念寡昧於道
不達罔測津涯故發此詠題庶幾明
白坦然矣。



。



夫道之妙也五行能之運化。



。



三才可以變通。



。



虎嘯龍吟陽唱陰和。



。



窮其秘也神明可辯於情狀。



。



究
其精也剛柔自符於易簡。



。



而惑者昧於修己攻乎
異端俟駕鶴而𩥵鸞猶繫風而捕影。




。



老氏五千之旨尚不
述於神仙。



。



莊周九萬之談理更超於言象。




。



先
賢󲏗脫皆知道而不言。



。



庸愚困蒙豈希
顏而議學。



。



昔
秦始皇邪見所惑徒望蓬萊。



。



漢武帝民力是輕莫尋員
嶠。



。



斯皆不修仁德求利好貪。



。



事蓋不經良足
太息。



。



今之
所述其殆庶乎。



。



或近取諸身。



。



或遠取諸物。



。



其詣理也不可以一途
執。



。



其筌意也不可以一理求。




。



探𧷤幽微。



。



㕘詳法
度。



。



智者見之謂之智仁者
見之謂之仁。



。



玄覽而可以照三清。



。



旁行而可
以通萬有。



。



夫詩頌歌辭華而不實。




。



上不足以補時政之
闕失。



。



次不足以
救蒼生之弊病。



。



假有獨擅其名弗精
於用。



。



義同畫餅棄不足󳏃。



。



爭如立至當之言
以濟於時世者哉。



。



所以姑
務契理不取於文。



。




貽尓方來悟夫懸解者矣。



。



御製逍遙詠卷第一







逍遙知語默




。




境外見真空




。




有位皆玄
感




。





無緣不用功




。




義說三才理




。




幽深萬事通




。




因依堪法則




。





荅謝向旻穹




。





大道虛無境




。




信之則有靈




。




幽深玄妙理




。




運轉幾曾停




。




拘束從何益




。




周通靜
杳󳸓




。




真空非作
相




。




善應保安寧




。





我自常安樂




。




凡
情勿笑耶




。




雲
生諸洞府




。




𣗥
不放仙花




。




地卑三光照




。




天開五色霞




。




未知何所是




。




善願理交加




。





我達逍遙理




。




陰陽運五行




。




道從初一變




。




德合混三清




。




聖
境堪依仗




。




狐疑事不成




。




異端違雅淡




。




返禍自輕生




。





逍遙人控鶴




。





碧落壓天津




。




達
理通含識




。




虛無即
是真




。




河車誰肯
信




。




鈆汞本相親




。




造化皆如此




。




今緣論宿因




。





何處堪依仗




。




經心便󲰶眉




。




世情多詭詐




。




業重信愚癡




。




取次招他謗





。




違非不自知




。




貌恭無德行




。




禍福在修持





。





虛無知大道




。




極意思悠然




。




摩日雲中
󳒙




。




瀟湘水
似天




。




孤峯高遠近




。




寶月瑩團圓




。




信解明開悟




。




青霄在目前




。





逍遙名有理




。




得一便知
空




。




道本背深邃




。




凡為不易窮




。





品流才雅淡




。




挌致意潛通




。




救世傳相益




。




因成順八風





。





誰測玄機聖




。




天功地久長




。




群生皆是性




。




道德有
圓方




。




妍醜
隨情意




。




於戲細酌量




。




達人知淡泊





。




默默見
非常




。





道德誰分別




。





逍遙我自由




。




時情人不達




。




深理少相投




。




已是終無益




。




非他作逗留




。




奈何為各異




。




未定復還休




。





奧義通玄化




。





精微妙入神




。




功程隨志願




。




貶降背於真




。




靜默堪為法




。




無言事可親




。




逢師傳口訣




。




金玉變埃塵




。





清靜真空理




。





不無解者難




。




縱橫依見性




。




廓落智中觀




。




坦
蕩歸仁德




。





辛勤久遠看




。




勿教為逆順




。




平地入雲端




。





𠃵坤常運轉




。




兀兀見眾生




。




利物
終相應




。




施為願要精




。




身慵何隱遁




。




舌辯謾
縱橫




。




種性歸真理




。




因緣有重輕




。





仙經無限意




。




龍虎返丹砂




。




採綴陰陽理




。




終期嵗月賖




。




求來皆有應





。




不信固難
誇




。




忙說閑
清境




。




真誠悟幾家





。





陽與陰和合




。




須從一字求




。





分明皆是象




。




作相不能投




。




舉措先
真實




。




精󱍮
各自柔




。




恒
持通覺悟




。




萬𣲖水東流




。





鈆汞精修鍊




。




陰陽恊物情




。




花開黃道正




。




藥就紫煙
輕




。




海嶠
浮雲合




。




神光照室明




。




彩霞高麗日




。




細意話長生




。





照然明道德




。




萬象有
其端




。




變
化疑誰信




。




超凡入聖看




。




幽玄深自在




。





眇邈就中難




。




但味風塵裏




。





方知宇宙寬




。





世界無窮盡




。




論
之遠更深




。




陰陽分皂白




。




瓦礫變黃金




。




報應終還有




。




邪求不易尋




。




忩忙
誰正定




。





須是合天心




。





世利貪拘束




。





欺心自不知




。




一
真求意在




。




四敘
絕參差




。




頓悟超諸聖




。





娛情改換癡




。




生
前如似夢




。




願
重細推之




。





愚癡常似醉




。




何異
夢中人




。




欲達終
無見




。




懷疑
道豈親




。




非為
貪閇口




。




郍是益
於身




。




先
生堪寂默




。




種福不傳因




。
