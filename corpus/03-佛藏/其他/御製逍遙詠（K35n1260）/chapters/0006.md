# 卷6

御製逍遙詠卷第六　輕





逍遙利樂認天真




。





心印深藏喻海津




。




妙法湏求經裏字




。




無緣勞問洞中人




。




研窮道德從何
入




。




清淨玄通馭物親




。




此語
苞含堪賞詠




。





丹臺羽客善鋪陳




。





於身日益但多為




。




賢聖何曾免是非




。




大道幾時明鄙隔





。




真宗
隱顯在玄機




。





周知物理通還感




。




俯仰從來有順違




。




冝且守恒
存禮讓




。




難中輕
重兩相依




。





神仙上界道清虛




。




𨚗箇何親𨚗箇
踈




。




修鍊豈教人世
識




。




歸真本是太陽
居




。




三天
定相玄中得




。





一氣湏聞妙更殊




。




運偶不同他往日




。




老來自
在見功夫




。





休話還丹大鼎爐




。




我緣
經歷盡皆虛




。




人閒豈有神仙藥




。




天上難開玉
匱書




。




彭祖自
勞閑歲月




。




穆王
謾說走龍駒




。





矜孤恤寡行公道




。




此乃名為利益殊




。





靈藥從來隱聖機




。




何人得達到玄微




。




真空入有皆知實




。




運化功能到者稀




。




汞裏金牙堪
可重




。




爐中白雪
共含輝




。




勿令陰
氣侵陽位




。




走作丹砂赫弈飛




。





時人不識理深玄




。




細意精修被業牽




。




幻化杳𡨋隨物性




。




虛無豈是亂
相遷




。




龍
飛入位真堪仰




。




虎
伏休閑有自然




。




洞
裏煙霞何縹緲




。




神
仙景致沒休年




。





澤瀉池塘灌藥畦




。




太清雲黯步紅霓





。




松花
鍊鼎龍山側




。




甲第群仙鳳鶴棲





。




分別要從華等級




。





微言道泰物湏齊




。




自吟自詠求
師侶




。




入品詩流旋作題




。





道高人世禮周旋




。




語默如癡似不言





。




洗滌要教心地靜




。




狐疑勿類水萍飜




。




經書說盡修真理




。




歲月休防罷引援




。




雅合無為深見識




。




陰陽去住促寒暄




。





猶龍景象駕翔鸞




。




道在虛無天地
間




。




一二合將歸大體





。




五千言外不
開關




。




儀
形眇邈難相類




。




聖
跡希夷語默閑




。




昔日西遊如似夢




。




化胡異域却應還




。





乹坤之內隱長生




。





藥變還丹道已成




。





救世神方堪自秘




。





樂耶語話勿相輕




。




眠雲臥水通玄識




。




點石為金誰辯眀




。




黃老身心皆得所




。




登壇善聽
步虛聲




。





大然五色被雲遮




。




聖境由來路逕󰫼




。




鍊礦勿教
侵外域




。




真鈆豈得離中華




。




苞含日月高還遠




。




自是人心識
見邪




。




龍浴鳳
池誰可意




。




神仙群聚笑唅呀




。





傾依慕善易為興




。




却𢙢人心冷似冰




。




含識昭然
何不達




。




非同物
類信誰憑




。




強其志莭皆知
有




。




未
盡任持早愛憎




。




倐忽便經閑歲月





。




凡閒聖
事可升騰




。





逍遙我詠杳𡨋中




。




萬物齊歸各異同




。




曉解精微無所著




。




先從含識踐
真空




。




希夷自變剛
柔理




。




述
作縱橫道不窮




。




剖判三才堪測度




。




輝華積德
上玄功




。





神丹妙道故延年




。




豈是凡流識大仙




。




老子尚猶能諱事




。




軒皇不許亂
相傳




。




誰知
造化功夫力




。




罕見今生度宿緣




。




猛虎伏來龍駕馭




。




雲騰五色思悠然





。





誰知學道本來真




。




鈆汞為媒㝡好親




。




非是虛傳經歲月




。




自緣無識探龍津




。




初凝白雪堪可貴




。




解點黃金妙入神




。




術數催驅依造化




。




老顏改作後
生人




。





非來非去亦非忙




。




所是凡為自短長




。




專志比徒
歸一等




。




誰
知禮度畏三光




。




相傳秖
要達真境




。




勿說辛勤却易傷




。




授得
道心皆語默




。




四時八節順陰陽




。





十洲洞府養神仙




。




幾說桒田屢變遷




。




老子商周為柱史




。




劉安拔
宅上青天




。




名山
隱遁非堪守




。





鍊藥修真本自然




。




想取儀形通感應




。




徒勞運智亂烹煎




。





真空達得便湏休




。





二起生三一上求




。




謾說希夷來遂古





。




還知
造化不同流




。





伏藏密旨機關內




。




合會非常本自由




。




若遇逢師親口訣




。




老年返少保千秋





。





見他顏貌未知年




。




便說人間壽一千




。




修鍊要門皆的實




。




行持法度甚精專





。




於身有
益何般是




。




指口
為眀道理全




。





更擬細窮方外事




。





無言無語上青天




。





大底緣由比類深




。




難中此道費光陰





。




若知濁浪
澄清水




。




不達浮生認白金




。




走作真珠藏妙理




。




究推神室好
相尋




。




功成穩
審時閒用




。




變轉無窮重古今




。





御製逍遙詠卷第六



甲辰歲高麗國分司大藏都監奉
𠡠彫造
