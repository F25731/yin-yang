# 卷9

御製逍遙詠卷第九　輕





還元到即見真歸




。




不是虛傳羽化飛




。




大道勿將閑設用




。




精修別得便𭜎機




。




安排
穩入龍宮內




。




變易終藏虎鼎威




。




豁達𠃵坤神妙
理




。




逍遙鈆汞共相依




。





鶴骨巖巖混世間




。




不侵寒暑似童顏





。




精神
爽麗言千典




。




舉步如飛思慮閑




。




起坐問他修鍊法




。




亂將詞理勿交
関




。





生來靜却凢愚見




。




又說三仙有大還




。





停騰火𠋫詰炎山




。




九轉方能濟世
間




。




玉蘃花開
真可愛




。




紅爐
鼎內境幽閑




。




人逢藥就延長久




。





羽駕仙迎返少顏




。





盡在目前非是遠




。




定
知時日好登攀




。





泥丸本是命根宮




。




消息臨時
語話通




。




大道比來行氣術




。




其餘効驗藉陰
功




。




物
情之理皆清淨




。




造化玄󳏧事莫同




。




󳏃重此言深
可意




。




腹中
日運鼎花空




。





無名蹤跡故難興




。




智者消詳冷似冰




。




廓落異端隨日變




。




乖違法度受天
懲




。




機
關勿使招他謗




。





亮直溫和自舉升




。




好事相宗堪䡄範




。




方言內外一般稱




。





天生顏㒵幾何般




。




鶴骨飡霞厭俗觀





。




赤水華
池誰法則




。




白銀為𮤢又
堪看




。




來傳音旨
俱然混




。





位有尊𢌿勿異端




。




逆順之中關理性




。




心田靜外豈相干





。





靈草靈砂起自然




。




却將非外亂烹煎




。




黃牙成土堪名藥




。




秋石為胎本是鈆




。




樂道逢來折且
喜




。




周知體
認更完全




。




陽施
陰授冝消息




。




不識時人在眼前




。





逍遙我命在玄穹




。




鶴宿霞󱡿景致中





。




自得安寧兼養道




。




更將利益屏群雄




。




淵深引古知今
用




。




劈斫區
分盡可通




。





和暢五音從豁達




。




𠃵坤之內靄溟濛




。





巔峯一望水深潭




。





誰解緣情語話堪




。





暗室自開眀日月




。





道心奇異老山菴




。




研窮妙理真消息





。




誡忌先賢讓不貪





。




稽古尚
為今法則




。




愚
蒙太甚苦談談




。





千年福壽自由人




。




萬象星羅
𠈟在身




。




寶馬不教龜鱉乳




。




嘉禾湏問穀田
神




。




根株種植華池內




。




藥鼎煎
催運火勻




。





混沌分來皆是道




。




二儀交感八方
親




。





非人口似瀉汾河




。




此軰塵中有甚
多




。




心恨㒵
恭無定止




。




舌誇
端正乱乖訛




。




為官
善政身榮祿




。




利劒
休教石上磨




。




立待
滿盈舡䧟水




。




惡風
從被海神拖




。





精詳語議四門開




。




舒慘陽和意外裁




。




遠見風塵思往事





。




無窮日月去
還來




。




樂耶
栺趣歸三體




。




周旋道理遍九垓




。




賢聖人天常
法則




。




𡖖
雲嶺上白皚皚




。





飛騰自在莫教󰫼




。




坎女离男共一家




。




無
礙逍遙通智慧




。




將求利樂勿湏誇




。




靈根就看和春
雪




。




神室之
中有絳砂




。




彼是彼非堪可重




。




常娥倚樹笑唅呀




。





貪染猶來理不通




。




虛勞嵗月面西東




。




從前自是
凡心別




。




利益湏歸上帝功




。




洞府名高
同景致




。




塵泥蹤跡莫知空




。




去非但向鈆中作




。




變化飛騰大道雄




。





達道真人見者稀




。




豈教容易等閑知




。




陰陽造化無非實




。




天地元精動合
冝




。




功行
三千湏及物




。





還丹九轉上昇時




。




忙中嵗月忙中遣




。




我本愚來性不移




。





拪心隱逸故非常




。




大約恒持要久長




。




清淨好
為皆是益




。




周旋理度審安詳




。




法𠃵馭物湏平穩




。




順日成功自酌
量




。




倐忽之間堪疋
配




。




臨時巧拙見圓
方




。





香湯沐浴更齋清




。




運動形軀四體輕




。




魔鬼自然生怕怖




。




神魂必
定轉安寧




。




從無入有皆真實




。




去住何難妙㝡
精




。




五行
聚散歸一體




。




靈源不用苦煎烹




。





一身獨善欲何之




。




爭及衣󲞈解撫綏




。




浮世淺情
無限量




。





愚蒙自是不相䂓




。




直須憑仗分眀說




。




詰取靈源問得知





。




要覔洞
中閑日月




。




除將濟事謾非為




。





尋思道味詠吟哦




。




去住先賢有幾何




。




性識
無凝関要妙




。




浮沉依
約不言多




。




但將子細分眀說




。




猶
恐閑非却被魔




。




救世比來心所願




。




逍遙盡入扣
玄歌




。





鈆汞丹方不謾論




。




同歸一體有玄門




。




剛柔產取黃牙樹




。




遠近
先眀赤水魂




。





化質昭然清日月




。




縱橫無礙杳𠃵坤




。




龍吟
虎嘯真非是




。




霧散雲飛似雨奔




。





御製逍遙詠卷第九



甲辰歲高麗國分司大藏都監奉
𠡠彫造
