# 卷11

御製逍遙詠卷第十一　　　輕


逍遙謌一首
逍遙賦一首
周穆王宴瑤池賦一首



逍遙謌一首




逍遙自在何拘束




。




天地希夷無返覆




。




勿把他心向外求




。




真宗理
道相和睦




。




人間天上盡修行




。




七寶山高混太清




。




玉樹玄珠明照室




。




命根悟者轉增盈




。




虛無入
有何蹤跡




。





非是神光化金液




。




廓落方圓在杳󳸓




。




南來北去斷消息





。




靈元物象
向天涯




。





古往今來聖事誇




。




無礙智通精進心




。




研窮理
路㸦交加




。




奇哉离
燄烹鈆水




。




清靜之中藏奧旨




。




出沒門󲊷
景異常




。




十洲
隱大神仙子




。




綿綿若
論太幽深




。




即是流
珠不是金




。




萬卷經
文兼在目




。





機關絕妙有浮沉




。




開關寤寐來相逼




。




魄
走魂歸天地力




。




風掃塵埃躡紫雲




。




覩其
顏㒵難別識




。




勿生疑慮變陰陽




。




須信丹砂道理長




。




若向此中明此義




。




十洲洞府蘊馨香




。




康哉內景植仙桂





。




枝葉
蔢䓾深根蒂




。




真宗妙法審來
由




。




修鍊真空無
涯際




。




要知
逆順莫相非




。




廣演周遮隱玄機




。





先說艱難後始說




。




精窮運
化遂相依




。




瑤池浴鳳通霄漢




。




金闕光舒何燦爛




。




丹成可驗不狐疑




。




常娥偷𥨱月中看




。





春間花卉一齊開




。




天上
優游誰肯來




。




洞裏煙霞牢秘隱




。




水精宮殿白皚皚




。




昔日神仙皆燒鍊





。




不說根由人豈見




。





本是凡情枉謾勞




。




何年待得成九
轉




。




密藏無使等閑知




。




碧落真如在兩儀




。




理外消停
造化實




。




相逢遇偶勿懷疑




。




直須
意遣凡庸道




。




所以難言論秘奧





。




先
令頓悟了然空




。




方扣玄關驅煩
惱




。




從來教法甚分明




。




幾許心迷事不成




。




棄世比圖閑自性




。




精修道路必長生




。




歸童返老超升界




。




正定威儀勿懈怠




。




開閇善能若苦勤




。




奮迅光陰同一泰




。




凡流學者不堅持





。




生滅門中故不知




。




走縮陰陽無
住相




。




非
難非易細推之




。




含胎
十月無休歇




。




或作金兮或似雪




。




認取還丹莫亂求




。




獼猴水底弄明月




。






逍遙賦一首




𠃵象推功




。




至道相宗




。




逍遙理而不散




。




赫弈高
而且通




。




信之者以陰陽




。




秘之者
以鈆汞




。




名恍惚之何異




。




見出沒之無窮




。




大道穹隆深仁常
在




。




騰三清
而靡息混四溟而不改




。




雲凝似雪
釋迷而頓悟虛无




。




鼎裏開花要妙
而熠揚光彩




。




想初神明闇契景貺優遊




。




子母成
而入聖




。




烏鵲飛
而逗遛




。




可
提撕而堪數




。




非雜類以相投




。




雲浮羽客之前方知
禮讓




。




洞府真人之喻𠕀測
端由




。




及乎偃仰無蹤




。




有為皆寂




。




窺其戶牖須憑刀
尺




。




千載遇而
可化




。




九轉成而
堪惜




。




達虧盈
而動止若之相望




。




訣逆順以所思潛遁其
跡




。




何謂清者濁之本濁者清之徒




。




風塵路合桂
影蟾孤




。




由久
恒持豈凡庸之能測




。




元和獨立辯玄化之精󱍮




。




然則難將語默
故不差殊




。




顯華夷之共泰




。




離煩惱之銷除




。




物臨幽奧眇邈真如




。




曷若習本
靈元故依人望




。




豈不知寰瀛之內修得歸
神仙之上




。




究龍
吟之走作海岳淵深




。




窮虎嘯之和平流珠通
暢




。




且夫性靜希夷




。




別識根基




。




信受而縱橫自
在




。




舉
措而照鑒形儀




。




清得而金牙燦爛




。




紅芳而碧葉交
垂




。




玉闕化成
滌蕩愚蒙之見




。




煙霞綺靡用茲廣達之知




。




於戲法教
門中研精秘旨




。




與陰陽而合德




。




寂天地而同理




。




還丹至藥




。




接聖境以周旋




。




日月齊明勿恣縱而
善矣




。




凡
在人間各有長生




。




我聒賢愚之耳




。






周穆王宴瑤池賦

。




馭駕神蹤




。




碧
落香風




。




靉靆之祥煙綺靡




。




縱橫之羽盖迎空




。




夜景迢迢意思而奔赴瑤席





。




天
高遠遠駈馳而直抵崑宮




。




當其渾雜駢羅




。




情分賔主




。




騰驤之駿馬何極





。




𣫍袂
之仙娥共覩




。





既而靈貺集




。




仙童侶




。




明月之圓將似晝組繡瑤池




。




金殿之高
卷珠簾笙歌伎女




。




志慕求真




。




儼雅深仁




。




輝華宴以初
設




。




光幸輦以爭新




。




珊瑚器皿




。




淥水波津




。




錦帳雲
屏去就傳觴之旨




。




鸞歌鳳
舞如常待客之陳




。




虎嘯龍吟




。




衣󲞈侍眾




。




筵斟玉液之醞




。




樂奏琴瑟之弄




。




鶴鳴天上思
羽駕而自在逍遙




。




日𣅳烏傾薄塵世以
從容舉動




。




時
也靈符降展情懽




。




贈玉帛以成禮





。




搖翡翠以㽵
端




。




筵中之百媚
花芳柳垂金線




。




階上之雙娥對舞殿列鴛
鸞




。




既
而窈窕周旋




。




徘徊不絕




。





水精宮間於碧沼




。




珠璣座臨於絳闕




。




九旒𭁺𰭍
日黯於東海之中




。




十
二樓臺風颺於西波之月




。




復還五色
雲頭萬𣲖分流




。





若木之金烏飛乍變




。




鏘風而白鹿鳴未
収




。




眉開八字兮
晶熒煙霞馥郁




。





歌聲一曲兮縹緲銀漢優游




。




何期遠恣情深





。




有無所得




。




瓊宮不讓於天
上




。




人間非外於縱
逸




。




終
乃是非起而慕求仙




。




如夢輕佻之客




。






御製逍遙詠歌賦卷第十一



甲辰歲高麗國分司大藏都監奉
