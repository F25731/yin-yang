# 卷4

御製逍遙詠卷第四　輕





白日眾生見




。




幾來得意人




。




萍蓬如似夢




。




丹鼎妙清神




。




紅樹非花影




。





青松𡑅海津




。




入玄龍虎伏




。




大道許相親




。





雅澹玄中得




。




常人
故不知




。




幽深無遠近




。




道外細推之




。




碧落神
仙境




。




煙霞日月隨





。




叅詳寰宇內




。




邪正豈相離




。





逍遙通物性




。




大道有圓方




。




山谷高深淺




。




人心自短長




。




陰陽窮豈竭




。




造化入無疆




。




塵埃飛
作垢




。




驚鴈不成行




。





群生各自意




。




未有一般般




。




名利貪嗔賊




。




愚迷道路寬




。




避煩如雨散




。




清靜入雲端




。




善想因緣理




。




經窮子細看




。





皇天無不照




。




福業
重來輕




。




背正堪
何益




。




歸真道自成





。




本元宗一體




。




功行錄三清




。




幾許解吾意




。




慈悲利益平




。





得道超凡聖




。




逍遙本是緣




。




群迷難解會




。




我且不虛傳




。





但信恒無斷




。




精
窮用意專




。





審聽眀譬諭




。




勿被俗情牽




。





物情通萬象




。




達者
便忘機




。




各具
含靈性




。




狐疑有
是非




。




知天修
福惠




。




如日瑩光輝





。




認取好
𭭛路




。





惡去善相依




。





經心玄妙理




。




道德念陰符




。




九轉金丹鼎




。





三才玉匱書




。





恒常皆隱秘




。




達者
見清虛




。




倐忽神眀
意




。




先賢覺自愚





。





天地含清泰




。




陰
陽道所成




。




冲和玄妙術




。




勿訝說長生




。




起信何疑
悞




。




迷來却
謗輕




。




攝
心歸正念




。





淡薄惡銷聲




。





混沌初分後




。




陰陽辯濁清




。




三才皆備位




。




萬物有長生




。




𠕀象精通
感




。




淳和道可眀




。




但求方寸
是




。





剖判應非輕




。





五色雲銷黯




。




方知大道深




。




華池玄妙理




。




龍虎本同音




。




金鼎
鈆中作




。




紅花洞裏尋




。




求真如得路




。




返少老山岑




。





達取真空性




。




成
名有後先




。




智勞
如似夢




。




恬澹
不論年




。




閇口恒持
默




。




精修更是玄





。




消停
湏在意




。




安穩上
清天




。





礦鍊真金色




。





菩提道果成




。




仙
人持忍辱




。




胥國
福眾生




。




教法堪依信




。




勤修猛要精




。





若能功行滿




。




故
是達三清




。





至藥家家有




。




誰
人解得麼




。





玄通真法界




。




妙理諭恒河




。




年歲銷風水




。




芝蘭間𣗥窠




。




陰功陽造
化




。




善少惡中
多




。





瘖瘂癡聾病




。




求醫大法王




。




貪瞋無相體




。




正定得清凉




。




達者通賢聖





。




迷情任意狂




。




分眀如是說




。




寂靜有閑忙




。





漸省虛名理




。




真求一味清




。




目前皆是景




。




心
內蘊長生




。




白
露秋催促




。




紅
花葉自輕




。




物
情歸即悟




。




疑滯
兩無成




。





紫陌紅塵裏




。




貪名利好爭




。





世情皆擾攘




。





大道甚縱橫




。




絃直
終無曲




。




心邪自不平





。




若能如遂意





。




後
學法先生




。





寂靜皆無語




。




其於理一般




。




若非通秘奧




。




故是入微端




。




善可名高尚





。




真乘
智識寬




。




天長與地久




。





萬物不相干




。





天上及天下




。




施為𨚗是親




。




物情歸造化




。




大道見深仁




。




果位非遙遠




。




賢愚自苦辛




。




焉知
皆日用




。




秋
換一年春




。





表裏分眀說




。




深窮妙更玄




。




愚迷行不到




。




聖事法
中傳




。




欲界情無定




。




真空本自然




。




今
生隨曩刧




。




清淨照三天




。





御製逍遙詠卷第四
