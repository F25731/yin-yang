# 卷10

御製逍遙詠卷第十　輕





道妙懷真紀異常




。




人間天上若存𰀄




。




潛機物類多中
覷




。




納取虛無定久
長




。




碧落遨遊
歸洞府




。




黃金
不買自馨香




。




叅同契合諸經說




。




精魄𡙸來爛紫光




。





無為道大入幽玄




。




幾許風光慕昔賢





。




對境盡同閑見識




。




忙中皆是急相煎





。




配匹直湏寬
雅淡




。




會有逢時不偶然




。




修鍊但教堅志氣




。




叅詳
穩審更周旋




。





含胎長養盡籠羅




。




豈離玄談道理麼




。




狐兔幾曾
能乳馬




。




麥田斷定不生禾




。




目前便是真佳境




。




汞內消停自
合和




。




認取門󲊷深見解




。




紅砂奇異湧恒河





。





人心多是少相投




。




非識塵中上品流




。




不見真宗
歸物理




。





難知妙道後先休




。




生前內鼎冝烹鍊




。




殊勝華池好漸修




。




但見完全憑土德




。




能調火𠋫
藥皆秋




。





玄之玄又見真空




。




巧拙臨時要妙中




。




大智伏藏知
遠近




。




纖󳏧盡達
了然通




。




周旋物
性誰區別




。




坦蕩由
來是且同




。




境致三
才隨有位




。




神光照室瑩西東




。





還丹未就且降魔




。




二八從教細攪和




。




离
火催駈凡入聖




。




坎鈆功力甚僂儸




。




紅塵自化真堪貴




。




白雪增盈不用多




。




九轉龍吟成虎嘯




。




人非人是狀巍峨




。





難求的當問愚癡




。




𨚗箇堪言好事知




。




名利猛貪無有足




。




多端動止沒䂓儀





。




浮生不
實將何用




。




欲把非常亂作為




。




謾語饒教能配類




。




一朝患害殢他誰




。





千般萬類不相逢




。




天地尊卑豈易窮




。




海岳高深隨
日轉




。




神仙聚樂隱塵中




。




鮮求名利知貪少




。




多事閑忙惣是空




。




幾
箇心賢平坦蕩




。




十洲三島自從容




。





含元得一本真宗




。




悞者平論惣是空




。




萬象都來皆俻𰚆





。




千言譬
諭了然通




。




才高俊彥優堪賞




。




竊祿偷安有異同




。




唯願他心
如似我




。





不教䧟惡罪身中




。





𠃵関萬象審消停




。




子母相傳日月精





。




產藥要教千
日化




。




玄門全藉五
行清




。




靈胎脫
體方知聖




。





鈆汞梯媒不是名




。




金鼎就來從變質




。




陽和陰氣兩俱生




。





九重天上帝仙居




。




愚
昧求真道理踈




。




混沌初分長日月




。




精魂聚散記
丹書




。




离男坎女
皆相類




。




壬子丙丁
異境殊




。




歷刧因緣隨世在




。




陰功及物㝡
玄殊




。





神水華池妙更精




。




非鈆非汞妄于
名




。




河車本
是延齡藥




。




戊子從教配類成




。




朱
雀坎虵安在後




。





青龍白虎免交爭




。




若使真金全二八




。




何憂
住世不長生




。





還知受氣稟天然




。




百法方為事理全




。




假合都來歸至道




。




修持遠大更
通玄




。




二儀交感成祥瑞




。




八卦剛柔被俗牽




。




何謂此中生恍惚




。




直湏欵曲細精研




。





玄門至道故無涯




。




自是人心所見邪




。




智識未能通大
藥




。




豈將容易
擬榮家




。




千年
聖境何虛󵘜




。




百刧曾修不用遮




。




龍虎欲成堪
鍊鼎




。




勿為利路
亂交加




。





論功湏是一陽初




。




二八調和作楷模




。




固濟但牢封密閉




。




莫教中道有差殊




。




依時消息
專心記




。




在
意停騰運火徐




。




日月無虧眀節𠋫




。




從容願所不躊躇





。





還丹百數細湏尋




。




以驗從來道理深





。




火𠋫混成如白屑




。




水中凝結
是黃金




。





循環復始周旋鼎




。




造化駈馳要用心




。




消息玄門窮八卦




。




飛騰自在遠
山岑




。





真空修鍊永長年




。




不識還丹在眼前




。




一得清來光宇宙





。




千朝湏是用烹煎




。




人間天
上分眀錄




。




汞裏花開豈偶然




。




達取
但教依理路




。




勿貪世利悞周旋




。





烘烘火色水中論




。




至寶湏教鼎內存




。




點化自然常在手




。




區分道理有玄門




。




莫將容
易誇言說




。




盡入
虛無是我尊




。




天動地神邪可畏




。





丹能飛走似雲奔




。





人是人非意頗同




。





較量此事盡歸空




。





無為政化求真理




。




方表深仁大道雄




。




舉止但能恒有節





。




尋思
何處不周通




。




寰瀛
善惡知多少




。




莫忘
生前積德功




。





因緣業障遇真稀




。




黃帝乘龍豈是非





。





達識尚凝常恍惚




。




愚蒙學解故相違




。




華池秘密人
天授




。




神
室光揚日月輝




。




智者無言皆
口嘿




。




敢將容易論玄
機




。





御製逍遙詠卷第十



甲辰歲高麗國分司大藏都監奉
𠡠彫造
