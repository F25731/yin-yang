# 御製詮源歌

御製詮源歌　　　　宗



詮源歌。



。



昔有佛者。



。



於五百世前
持忍辱緣。



。



妙
覺如來本大仙。



。



苦行慧超昬衢暗。



。



三昧因中
人不見。



。




救度眾生蘊慈悲。



。




無量刧來多發願。



。



方便門開智慧觀。



。



萬法從頭皆一貫。



。



道
行清高何障礙。



。



五濁惡世堪修鍊。



。



堪修鍊。



。



歸至理。



。



無邊國土恒沙水。



。



圓滿化身知不
知。



。



七寶湏󳇐納芥子。



。



芥子細。



。



人行󱍮。



。



雪山
清淨是真如。



。



真
如果證信心重。



。



降下山河皆
搖動。



。




舉步蓮花崛山中。



。




帝釋梵王相迎送。



。



般若智。



。




破煩惱。



。



根性自然菩提道。



。



清淨色空
座逍遙。



。




󳇐勒緣寂無顛倒。



。



比丘僧。



。



比丘尼。



。



來聽法。



。



唯願
慈悲分解說。



。



故非眇小是修
行。



。



經戒相違有罪業。



。




善男子。



。



善女人。



。



愛河不
渡䧟迷津。



。



波羅蜜相真
堪信。



。



遠離
六情果從因。



。



果從
因。



。



豈願足。



。



深淺隨機皆是欲。



。



達磨之心終不曲。



。



品度俱為
䪺漸久。



。



戶牖
開張相擊觸。



。



大
攪長河為酥酪。



。



覺悟賢眀迷自縛。



。



舉
體全歸三界空。



。



病
藥施投㸦更作。



。



振綱領
而無強弱。



。



邪妄若來皆銷爍。



。



一切隨
緣有是非。



。



世尊利益心安樂。




。





御製詮源歌
