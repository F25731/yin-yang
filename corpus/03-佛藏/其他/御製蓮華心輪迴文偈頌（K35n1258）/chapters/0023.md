# 卷23

御製蓮華心輪廻文偈頌卷第二十三　富





加護持力




。




蘊實真如




。





約理敷暢




。




狂昧自除




。




雄
名絕代




。




識洞虛無




。




勿乖準的




。




便同䡄
摸




。




顛倒成癖




。




猶豫凡夫




。




蓮花臺上




。




競作
仙鳬




。




淺近世俗




。





月影水壺




。




緣藉雖淨




。




苦樂昭蘇




。




差別眾異




。




悉得
勤劬




。





握符布政




。




信及豚魚




。




研窮境界




。




散在
清虛




。




豈將紕繆




。




所擬難乎




。




因無間隟




。




徧滿丘墟




。




風飄暴起




。




妄想閻浮




。




潛通惠愛




。




九類嗟呼




。




幽微經律




。




隨意眀珠




。




論愚癡謗




。




發跡多途




。




威光熾盛




。




戒細人󱍮





。





金文祕藏




。




咸感四
隅




。




燃燈暗室




。




日月光舒




。





御製蓮華心輪廻文偈頌卷第二十三



甲辰歲高麗國大藏都監奉
𠡠彫造
