# 卷24

御製蓮華心輪廻文偈頌卷第二十四　富





朝旌禮讓




。




動振紀綱




。




功
齊譽要




。




譬喻莫量




。




行其道德




。





以順陰陽




。




廻向利樂




。




瑞氣騰芳




。




連綴貫穿




。




俓取顯揚




。




星搖碧落




。




夜月恒常




。




恩流解
󱶈




。





奢誡彫墻




。




釋典重譯




。




陟眀遐昌




。




基開億兆




。




齋潔
蒸嘗




。




人祛諂媚





。




遠播馨香




。




正圓妙智





。




率
土寧康




。




聲聞󳭪廓




。




異義渺
茫




。




凝流警蹕




。




法作津梁




。




狡猾皆息





。





游墮馴良




。




小邦請
命




。





上國觀光




。




豐財重施




。




瞻仰汪洋




。




歸依佛法




。




如渴思漿




。




妖氛已弭




。





令肅嚴霜




。




朝諸太極




。




制斷明
堂




。




山林蓊欝





。




谷嚮投荒




。
