# 卷22

御製蓮華心輪迴文偈頌卷第二十二　富





起習方便




。




化導
無垠




。




明歸宗旨




。





述作通神




。




隨機諷誦




。




殊勝上因




。




始於戒㝎




。




名契俱真





。




應根本
故




。




常正法輪




。




微言立
教




。




和煦陽春




。




疑惑未斷




。




似蟻環循





。




依憑敘事





。




不染六塵




。





瞽者書字




。




跛者負薪




。




般若等智




。




彼岸
之津




。




修隱密
相




。




清淨於身




。




怯而無猛




。




富不憂
貧




。





普為轉照




。




金剛寶󳏃




。





論其所著




。




懽喜
滅嗔




。




當審思察




。





喻主𨒦賔




。




消磨狹劣




。





煩惱舒伸




。




五位修種




。




三性貞純




。




量包天地




。




覆燾
沉淪




。




非多演釋




。




濟拔群民




。




斯
遣妄執




。




讚施平均




。





御製蓮華心輪迴文偈頌卷第二十二
