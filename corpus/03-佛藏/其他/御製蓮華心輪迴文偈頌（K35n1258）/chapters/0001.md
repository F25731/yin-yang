# 卷1

御製蓮華心輪廻文偈頌卷第一　富




朕聞。



。




如來妙法理深也。



。



不可
輕易而銓量。



。



真諦奧玄智廣也。



。




豈非邪見而測度。



。



諒慈悲而攝受諸相。



。



匪
宏遠而導達有情。



。



救度群生胎𡖉濕化。



。



開大利益示現傍通。



。



喻說
分眀。



。



遠離於昬濁顛倒。




。



人我
執著。



。



可超於智慧菩
提。



。



發自
予懷。



。



而
成斯偈。



。



破煩𢙉障。




。



入
修行門。



。



達彼岸而精進無邊。



。




渡苦海而逍遙自在。



。



將其小
善。



。



普
施眾生。



。



且
夫萬仞山高。



。



劫盡而尚為灰燼。




。



五慾業重緣牽而海變桒田。



。




悟三乘者不戀愛河。



。



明四智者常居淨土。



。



曉浮生於幻夢覺塵
世若浮泡。



。



每行化俗之方。



。



󷘹
招真空之理得而自樂退想忘情。



。



朕機務之餘留
心釋典。



。



乃搆廻文之偈精求玄妙之
源。



。



起因一章終成千首。



。



舒展狀蓮開
一朵。



。



聯綴似月彩初圓。




。



立名曰蓮華迴文偈。



。



深非帝王之能事媿辤以
縱橫。



。



隨分可觀甚為魯質。



。



兼詔高僧注解稍究根
源。



。



大振於
寶鐸金文。



。



貫穿於玄言妙旨。



。



永
作津梁而濟沉溺。



。



常為慧炬以破昬迷。



。



俾使信心咸知朕意。




。



今雕成圖像
注并偈頌共二十五卷具列于後。
