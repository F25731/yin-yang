# 卷25

御製蓮華心輪廻文偈頌卷第二十五　富　





曉其逆順




。




如草隨風




。




惣摽三喻




。




器用周通




。




境
外取捨




。





萬類皆空




。




譬由蟬󲯏




。




夢𥧌不同




。




但
去󱍮𢙣




。




宇宙齊功




。




𡨋心著像




。




坐臥勿慵




。




敦兮若朴




。




絕學優隆




。




開𨶩戶牖




。




恍惚其中




。




知白守黑




。




闇昧和融




。




自矜者溢




。




鮮𠑽有終




。




蠢尓
生植




。




覆載清崇




。




盈虧莫究




。




上叩玄穹




。




寒熱增忍




。




鑒照盲聾




。




賤而
不貴




。




惠必英聡




。




狐狸邪患




。




蜂蠆怔忪




。




寢食無暇




。




飢改秊豐




。




海晏安靜




。




勇猛從容




。




讒滅盡去




。




比屋可封




。




囹圄寬宥




。




桎梏摧兇




。




處薄持儉




。




𣗥變
花叢




。





御製蓮華心輪廻文偈頌卷第二十五



甲辰歲高麗國大藏都監奉
𠡠彫造
