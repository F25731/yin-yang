# 卷21

御製蓮華心輪廻文偈頌卷第二十一　富





人天法界




。




善因惡緣




。




聡明智廣




。




彼我相纏




。




槯魔
眾苦




。




唯識自然




。




覺他圓
滿




。




空寂大千




。




慈悲攝
受




。




勝道存焉




。




精窮妙
行




。





取捨周旋




。




愛河湏渡




。





淤泥生蓮




。




來而復往




。




運有推遷





。




邪見強執




。




得意忘筌





。




三乘
解脫




。





一悟󳇐堅




。




恒沙
劫𰚆




。




救度無
邊




。




襃掦難
盡




。




喻
出幽玄




。




甚深之法




。




福
業平宣




。





經閞奧義




。





如水流泉




。




聲聞菩薩




。




䪺解唯賢





。




知其佛土




。




性識功全




。




分明遍
照




。





諦信心虔




。




因從果證





。





儼雅八埏




。




觀時願重





。




禮懺於先




。





貫諸真體




。




興
問齊肩




。





御製蓮華心輪迴文偈頌卷第二十一



甲辰歲高麗國大藏都監奉
𠡠彫造
